## Usage


```rust
use refineui::prelude::*;

Skeleton::new().shape(SkeletonShape::Text).width(px(240.));
```

Open the live, interactive version in the gallery:

```sh
cargo run -p refineui-gallery -- --story skeleton
```

## Motion

Opacity pulses 1 → 0.5 → 1 every 1.5s; static under reduced motion.

Source: [`crates/refineui/src/components/skeleton.rs`](https://github.com/pelagornis/refineui-desktop/blob/main/crates/refineui/src/components/skeleton.rs)

### Skeleton

Loading placeholder.

| Method | Description |
| --- | --- |
| `fn new() -> Self` | Default rectangle (full width, 20px tall). |
| `fn shape(mut self, shape: SkeletonShape) -> Self` | Shape. |
| `fn width(mut self, w: Pixels) -> Self` | Width. |
| `fn height(mut self, h: Pixels) -> Self` | Height. |
| `fn animate(mut self, animate: bool) -> Self` | Disable the pulse (e.g. for reduced motion or screenshots). |

### SkeletonShape

Shape.

| Variant | Description |
| --- | --- |
| `Rect` | Rounded rectangle (default). |
| `Circle` | Circle (avatar placeholder). |
