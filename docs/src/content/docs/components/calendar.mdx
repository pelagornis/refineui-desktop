## Usage

- Matches the web `Calendar`: a 256px-min card (`p-medium`, `roundedXXLarge`) with prev / next chevrons at the ends of the header and ghost month (`Jan`…) and year selects between them; the year list runs from 50 years before the earlier of the viewed and current year to 10 after the later one.
- The grid always has six week rows (42 cells). Days outside the month are dimmed; clicking one jumps to its month. There is no "today" mark (the web has none).
- `week_starts_on(1)` starts weeks on Monday (web `weekStartsOn`; default 0 = Sunday).
- `Calendar::range` shows two months side by side. Each month is headed by the same ghost month and year Selects as single mode (prev chevron on the left month, next on the right, the Selects centered; picking in the right month moves the view so that month shows the pick). The web shows a `subtitleMd` “November 2026” caption there; RefineUI desktop keeps both modes alike. Other-month slots stay empty, the endpoints are brand cells on a band and the days between are square `backgroundPrimaryHover` cells. A reversed range is swapped.

```rust
use refineui::prelude::*;

Calendar::new("due", Date::new(2026, 11, 1))
    .selected(self.due)
    .on_select(cx.listener(|this, d: &Date, _, cx| {
        this.due = Some(*d);
        cx.notify();
    }));
```

Open the live, interactive version in the gallery:

```sh
cargo run -p refineui-gallery -- --story calendar
```

## Motion

Day plates tween over `duration-normal` (emphasized) and press to 0.96; range mode shows two months with an endpoint band.

## API

Source: [`crates/refineui/src/components/calendar.rs`](https://github.com/pelagornis/refineui-desktop/blob/main/crates/refineui/src/components/calendar.rs)

### Calendar

Month view with previous/next navigation. Uncontrolled month, controlled selection.

| Method | Description |
| --- | --- |
| `fn new(id: impl Into<ElementId>, month: Date) -> Self` | Calendar initially showing `month`. |
| `fn selected(mut self, d: Option<Date>) -> Self` | Selected date. |
| `fn range(mut self, start: Option<Date>, end: Option<Date>) -> Self` | Range mode with the current `start` / `end` (web `mode="range"`). |
| `fn week_starts_on(mut self, day: u32) -> Self` | First weekday column (web `weekStartsOn`): 0 = Sunday (default), 1 = Monday. |
| `fn on_select(mut self, f: impl Fn(&Date, &mut Window, &mut App) + 'static) -> Self` | Date click. |
| `fn on_range_change(mut self, f: impl Fn(Option<Date>, Option<Date>, &mut Window, &mut App) + 'static) -> Self` | Range change (range mode), see `next_range`. |
| `fn bare(mut self, bare: bool) -> Self` | Drop the root border / fill (web `calendarContent` inside DateInput). |

### Date

A calendar date (proleptic Gregorian).

| Method | Description |
| --- | --- |
| `fn new(year: i32, month: u32, day: u32) -> Self` | New date (not validated beyond clamping the day). |
| `fn weekday(self) -> u32` | Day of week, 0 = Sunday. |
| `fn today() -> Self` | Today's date (UTC, from the system clock). |
| `fn add_months(self, delta: i32) -> Self` | First day of the month `delta` months away. |

### CalendarMode

Selection mode (web `CalendarMode`).

| Variant | Description |
| --- | --- |
| `Single` | One date. |
| `Range` | A start and end date over two months. |

### Functions

| Function | Description |
| --- | --- |
| `fn days_in_month(year: i32, month: u32) -> u32` | Days in a month. |
| `fn next_range(start: Option<Date>, end: Option<Date>, d: Date) -> (Option<Date>, Option<Date>)` | Next `(start, end)` after picking `d` (web `onRangeChange` rules): a first pick (or a pick after a complete range) starts over; a second pick before the start swaps the ends. |
