Floating mega panel centred under the bar (web `NavigationMenuContent layout="floating"`).

<Screenshot id="navigation-menu-mega" alt="Navigation Menu · Mega variants and states" />

## Usage

- **Optional** — behind the `web-extras` cargo feature (web-oriented, not part of Desktop Core): `refineui = { version = "0.1", features = ["web-extras"] }`.
- Centred in the window (clamped 8px from the edges), 4px below the trigger, at most 1000px wide (`navigationMenuMegaWidth`).
- `backgroundPrimary` fill, hairline `borderDefault`, `roundedXXLarge`, raised shadow.

```rust
use refineui::prelude::*;

NavigationMenu::new("nav")
    .panel("Products", NavigationLayout::Floating, |_, cx| mega_columns(cx).into_any_element());
```

Open the live, interactive version in the gallery:

```sh
cargo run -p refineui-gallery -- --story navigation-menu-mega
```

## Motion

The panel fades in and rises 6px over `duration-normal` (emphasized); closes over `duration-fast`.

## API

Source: [`crates/refineui/src/components/navigation_menu.rs`](https://github.com/pelagornis/refineui-gpui/blob/main/crates/refineui/src/components/navigation_menu.rs)

### NavigationLayout

Panel treatment (web `NavigationMenuContent layout`).

| Variant | Description |
| --- | --- |
| `Dropdown` | Compact frosted panel under the trigger (default). |
| `Floating` | Wide "mega" panel centred in the window under the bar, ≤ 1000px (`navigationMenuMegaWidth`), on `backgroundPrimary`; fades and rises 6px over `duration-normal` (emphasized). |
| `Overlay` | Full-width sheet from the bar's bottom edge over a scrim; its height grows over `duration-panel` (panel curve). Hovering or clicking the scrim closes it. |
