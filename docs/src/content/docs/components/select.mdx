## Usage

- Parts match web `Select`: trigger, value, content, group / label, separator, item, and a leading check item indicator. Scroll-up / scroll-down buttons exist on the web as empty stubs and are not rendered here.
- Open with click, Enter, Space, ↓ or ↑; arrows move (skipping disabled items); Home / End jump; typeahead matches the first letter of `label` / `text_value`; Enter or Space picks; Escape closes.
- `Select::new` still takes a flat list of labels. Add structure with `group`, `separator`, `item` or `entries` (`SelectEntry::{Item, Label, Separator}`). `SelectOption` carries `value`, `label`, `disabled` and `text_value`. `on_change` reports the item index (labels and separators are skipped).
- Sizes `sm | md | lg` and appearances `filled | ghost | plain`, plus `disabled`, `placeholder` and `full_width`, match the web.
- Placement matches the web default (Radix item-aligned, `place_item_aligned`): the popup covers the trigger and the selected row (or the first enabled row when nothing is selected) sits exactly over the trigger value, with the row text lined up with the value text. Collision detection keeps it inside `collision_padding` (default 10): when the rows above the selection do not fit between the window top and the trigger, the popup starts at the top edge and its internal `ScrollArea` is scrolled so the row still lands on the trigger; near the bottom it grows upward instead. It is at most the padded window height (scrolling inside when the list is longer) and at least five rows tall, which can shift it off exact alignment near an edge while still covering the trigger. Like the web (Radix `SelectViewport` scroll expansion, `expand_on_scroll`), a popup opened shorter than the window grows as the list scrolls (wheel, trackpad, scrollbar or arrow keys) before it really scrolls: a popup that starts at the top edge grows down, one that rests on the bottom edge grows up, until it reaches the padded window height or the whole list; the trigger stays covered and the alignment on open is unchanged. The native-blur pop-up window uses the same geometry, scroll and expansion, and resizes itself (keeping the anchored edge) as it grows. Placement is recomputed every frame from the trigger and viewport bounds, so resize and ancestor scroll stay in place.
- The list shell uses `rounded-xx-large`, a hairline `border-default`, `p-xx-small` and the frosted surface; items are `p-x-small`, `rounded-large`, `bodyMd`, with a 16px leading check slot. The popup is at least as wide as the trigger (plus the text offset) and fades in place over `Motion::FROSTED` (180ms), without sliding, so the selected row never leaves the value.

```rust
use refineui::prelude::*;

Select::new("tz", [] as [&str; 0], self.zone)
    .placeholder("Timezone")
    .group("North America", ["Eastern Standard Time", "Pacific Standard Time"])
    .group("Europe", ["Greenwich Mean Time", "Central European Time"])
    .width(px(280.))
    .on_change(cx.listener(|this, ix: &usize, _, cx| {
        this.zone = Some(*ix);
        cx.notify();
    }));
```

## Motion

The popup fades in with the frosted-surface motion, sliding a few pixels out of the trigger along `SelectLayout::transform_origin` (the web `--refineui-select-content-transform-origin`). A hover plate slides between options; trigger and items scale to 0.98 when pressed.

### Select

Single-choice dropdown.

| Method | Description |
| --- | --- |
| `fn new(id: impl Into<ElementId>, options: impl IntoIterator<Item = impl Into<SharedString>>, selected: Option<usize>) -> Self` | New select. |
| `fn placeholder(mut self, p: impl Into<SharedString>) -> Self` | Placeholder when nothing is selected. |
| `fn size(mut self, size: ControlSize) -> Self` | Size. |
| `fn appearance(mut self, a: SelectAppearance) -> Self` | Trigger appearance. |
| `fn disabled(mut self, disabled: bool) -> Self` | Disabled. |
| `fn width(mut self, w: gpui::Pixels) -> Self` | Fixed width (default: fill parent). |
| `fn default_open(mut self, open: bool) -> Self` | Start with the list open (first frame only; used by the gallery screenshot of the open popup). |
| `fn collision_padding(mut self, padding: f32) -> Self` | Window-edge padding the popup is kept inside when it shifts or shrinks (web `CONTENT_MARGIN` / `collisionPadding`, default 10). |

| `fn group(mut self, label: impl Into<SharedString>, options: impl IntoIterator<Item = impl Into<SelectOption>>) -> Self` | Append a group label and its items (web `SelectGroup` + `SelectLabel`). |
| `fn separator(mut self) -> Self` | Append a divider (web `SelectSeparator`). |
| `fn item(mut self, option: impl Into<SelectOption>) -> Self` | Append a single item (web `SelectItem`). |
| `fn full_width(mut self, on: bool) -> Self` | Stretch to the parent's width (web `fullWidth`). Already the default when `Self::width` is not set. |

### SelectOption

One selectable row (web `SelectItem`).

| Method | Description |
| --- | --- |
| `fn new(label: impl Into<SharedString>) -> Self` | An enabled option whose value and label are `label`. |
| `fn value(mut self, value: impl Into<SharedString>) -> Self` | An option with a distinct `value` and `label`. |
| `fn disabled(mut self, disabled: bool) -> Self` | Disabled option. |
| `fn text_value(mut self, text: impl Into<SharedString>) -> Self` | Typeahead text (defaults to the label). |

### SelectEntry

A row in the Select popup: an item, a group label, or a separator (web `SelectItem` / `SelectLabel` / `SelectSeparator`).

| Variant | Description |
| --- | --- |
| `Item(SelectOption)` | Selectable option. |
| `Label(SharedString)` | Group heading (web `SelectLabel`). |
| `Separator` | Visual divider (web `SelectSeparator`). |

### SelectLayout

Placement of an open Select popup. Alias of `FloatingLayout`; see that type for the mapping to `--refineui-select-content-available-height`, `--refineui-select-trigger-height`, and `--refineui-select-content-transform-origin`.

### FloatingLayout

| Method | Description |
| --- | --- |
| `fn origin(self) -> Point<Pixels>` | Top-left origin as a GPUI point. |

### ItemAlignedMetrics

Measurements of an item-aligned list, all in the panel's local space (`0` = the panel's outer top / left edge, including its border).

### FloatingSide

Preferred (and resolved) vertical side of a floating panel. For an item-aligned panel it is the edge the panel grows from: `Bottom` when it aligns without top overflow, `Top` when it starts at the top edge.

| Variant | Description |
| --- | --- |
| `Bottom` | Below the trigger. |
| `Top` | Above the trigger. |

| Method | Description |
| --- | --- |
| `fn opposite(self) -> Self` | The opposite side. |

### CollisionOptions

| Method | Description |

### TransformOrigin

Local point inside the panel used as a CSS-style transform origin.  Maps to the web custom property `--refineui-select-content-transform-origin` (a CSS string such as `"160px 0px"`).

| Method | Description |
| --- | --- |
| `fn to_css(self) -> String` | CSS value for `--refineui-select-content-transform-origin`. |
