## Usage

- Prefer `TextRole` (bodyLg, labelMd, captionSm, titleMd …) — the same semantic roles as the web `Text` component.
- `TextVariant` mirrors the raw Foundation tokens (heading1…caption3).

```rust
use refineui::prelude::*;

Text::new("Settings").role(TextRole::TitleMd);
Heading::new(2, "Settings");
Text::new("Changes are saved automatically.").color(TextColor::Secondary);
Label::new("Name").required(true);
```

Open the live, interactive version in the gallery:

```sh
cargo run -p refineui-gallery -- --story text
```

## API

Source: [`crates/refineui/src/components/text.rs`](https://github.com/pelagornis/refineui-gpui/blob/main/crates/refineui/src/components/text.rs)

### Text

A run of text styled with a typography token.

| Method | Description |
| --- | --- |
| `fn new(text: impl Into<SharedString>) -> Self` | Body text. |
| `fn variant(mut self, variant: TextVariant) -> Self` | Typography role. |
| `fn role(mut self, role: TextRole) -> Self` | Semantic role (web `variant`, e.g. `TextRole::BodyMd`). |
| `fn color(mut self, color: TextColor) -> Self` | Color role. |
| `fn truncate(mut self) -> Self` | Single line with ellipsis. |
