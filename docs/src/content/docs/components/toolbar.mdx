## Usage

- Buttons default to `Ghost` and inherit the toolbar size (default `Small`).
- `attached(true)` (default) draws the floating bar: hairline `borderSubtle`, `backgroundSurface`, 4px padding, raised shadow.
- ← / → move focus between the toolbar items.

```rust
use refineui::prelude::*;

Toolbar::new("format")
    .label("Formatting")
    .group(ToolbarGroup::new()
        .toggle(ToggleButton::icon_only("bold", IconName::Edit, self.bold)))
    .divider()
    .button(Button::icon_only("copy", IconName::Copy).tooltip("Copy"));
```

Open the live, interactive version in the gallery:

```sh
cargo run -p refineui-gallery -- --story toolbar
```

## Motion

Buttons and toggles keep their own press and plate motion.
