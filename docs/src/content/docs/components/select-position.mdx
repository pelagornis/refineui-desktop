Collision-aware Select placement: popper flip, constrained height with scrolling, and item-aligned overlay.

<Screenshot id="select-position" alt="Select Position variants and states" />

## Usage

- `SelectPosition::Popper` opens below the trigger and flips above (or to the side with more room) when it would overflow. Height is constrained to the available space — not a fixed max-height alone — and the list scrolls in a `ScrollArea`.
- `SelectPosition::ItemAligned` (Radix default) overlays the selected row on the trigger, shifting and scrolling so it stays in view.
- Padding and offset are `collision_padding` (default 10) and `side_offset` (default 4). Placement is a pure function in `components::positioning` (`place_popper`, `place_item_aligned`) so Menu, Dropdown and Popover can reuse it.
- GPUI has no CSS variables; `FloatingLayout` / `SelectLayout` exposes `--refineui-select-content-available-height`, `--refineui-select-trigger-height` and `--refineui-select-content-transform-origin` (`TransformOrigin::to_css`). The open animation slides from that origin.

```rust
use refineui::prelude::*;

Select::new("tz", zones, Some(0))
    .position(SelectPosition::Popper)
    .collision_padding(10.)
    .side_offset(4.)
    .width(px(280.));
```

Open the live, interactive version in the gallery:

```sh
cargo run -p refineui-gallery -- --story select-position
```

## API

Source: [`crates/refineui/src/components/select.rs`](https://github.com/pelagornis/refineui-gpui/blob/main/crates/refineui/src/components/select.rs)

### SelectPosition

How the popup is placed relative to the trigger (web `position`).

| Variant | Description |
| --- | --- |
| `ItemAligned` | Radix default: the selected item overlays the trigger (macOS pop-up button style), shifting and scrolling to stay in view. |
| `Popper` | Below the trigger (or above when there is not enough room), with `Select::side_offset` and collision flipping. |

### FloatingLayout

Result of collision-aware placement.  Field mapping to the web Select CSS variables:  \| Field \| Web custom property \| \| --- \| --- \| \| `Self::available_height` \| `--refineui-select-content-available-height` \| \| `Self::trigger_height` \| `--refineui-select-trigger-height` \| \| `Self::transform_origin` (via `TransformOrigin::to_css`) \| `--refineui-select-content-transform-origin` \| \| `Self::side` \| data-side (`top` / `bottom`) \|

| Method | Description |
| --- | --- |
| `fn origin(self) -> Point<Pixels>` | Top-left origin as a GPUI point. |

### CollisionOptions

Padding from the viewport edge and gap from the trigger.

| Method | Description |
| --- | --- |
| `fn new() -> Self` | Defaults (`collision_padding` 10, `side_offset` 4). |
| `fn collision_padding(mut self, v: f32) -> Self` | Viewport-edge padding. |
| `fn side_offset(mut self, v: f32) -> Self` | Trigger-to-panel gap (popper). |
