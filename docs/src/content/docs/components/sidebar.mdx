## Usage

- Inside a `ResizablePanel` use `.fill()`; standalone, `.width(px)` + `.collapsed(bool)` animates the width to 0 with the rail frozen.
- `sidebar_trigger(id, open, on_toggle)` is the web `SidebarTrigger` (secondary, `panel-left`).
- `SidebarPeek` floats a frosted copy in from the left edge while the sidebar is collapsed (hover the 12px edge for `duration-medium`).
- The content region is a `ScrollArea`, so group rows get the edge blur; footer rows do not.

```rust
use refineui::prelude::*;

ResizablePanelGroup::new("app")
    .panel(
        ResizablePanel::new().size(32.).min_size(0.).max_size(48.).child(
            Sidebar::new("nav")
                .fill()
                .brand("RefineUI")
                .group(Some("Product"), [SidebarItem::new("overview", "Overview").icon(IconName::Search)])
                .footer_item(SidebarItem::new("account", "Pelagornis").icon(IconName::Person))
                .selected(self.route.clone())
                .on_select(cx.listener(|this, id: &SharedString, _, cx| {
                    this.route = id.clone();
                    cx.notify();
                })),
        ),
    )
    .handle(ResizableHandle::new().with_handle(true))
    .panel(ResizablePanel::new().size(68.).min_size(30.).child(main))
```

Open the live, interactive version in the gallery:

```sh
cargo run -p refineui-gallery -- --story sidebar
```

## Motion

A hover plate slides between links over `duration-medium` (emphasized); link color and the active plate tween over `duration-fast`; collapsing animates the width over `duration-panel` (panel curve) with the rail frozen; the peek panel slides in over `duration-overlay` (standard).

### SidebarPeek

Web `SidebarPeek` (contained mode): while the docked sidebar is collapsed, resting on the 12px left edge for `duration-medium` slides a floating frosted copy in (`duration-overlay`, standard easing). Leaving both the edge and the panel closes it after `duration-medium`. The panel has a pin button (ghost `panel-left`) that re-docks the sidebar.  Put it in a `relative()` container over the main area; it renders the edge strip and the floating panel as absolute children.

| Method | Description |
| --- | --- |
| `fn new(id: impl Into<ElementId>, enabled: bool, width: Pixels) -> Self` | New peek layer, `width` = flyout width. |
| `fn panel(mut self, el: impl IntoElement) -> Self` | The sidebar to show (use `Sidebar::embedded` + `Sidebar::fill`). |
| `fn on_pin(mut self, f: impl Fn(&mut Window, &mut App) + 'static) -> Self` | Pin button handler (re-dock). |
