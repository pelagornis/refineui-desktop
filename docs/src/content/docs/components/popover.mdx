Anchored floating panel with rich content and a beak.

## Usage

- The content closure receives a `close` callback.
- Opens below the trigger, centered by default (`placement(AnchorSide::…)` / `align_end()` / `.align(...)`). The 24×12 beak and the panel are one closed outline; the beak aims at the trigger midpoint, clamps off the corner radius, and follows a flip when the preferred side does not have room.

```rust
use refineui::prelude::*;

Popover::new("dims", Button::new("open", "Open").variant(ButtonVariant::Secondary), |close, _, _| {
    v_stack(16.)
        .child(Text::new("Dimensions"))
        .child(Button::new("done", "Done").on_click(move |_, _, cx| close(cx)))
        .into_any_element()
});
```

Open the live, interactive version in the gallery:

```sh
cargo run -p refineui-gallery -- --story popover
```

## Motion

Fades in and slides 6px away from the trigger over `duration-fast` (emphasized), like the web `useFloatingPresence` (the web 0.96 scale is not reproducible in GPUI).

| Method | Description |
| --- | --- |
| `fn new(id: impl Into<ElementId>, trigger: impl IntoElement, content: impl Fn(Rc<dyn Fn(&mut App)>, &mut Window, &mut App) -> AnyElement + 'static) -> Self` | New popover (bottom placement, centered — web defaults). |

| `fn force_open(mut self) -> Self` | Render the panel open, in flow (for docs / screenshots). |

### PopoverAlign

Panel alignment against the trigger — web `PopoverAlign`.

| Variant | Description |
| --- | --- |
| `Start` | Panel start edge flush with the trigger's start edge. |
| `Center` | Panel centered under the trigger (web default). |
| `End` | Panel end edge flush with the trigger's end edge. |

### Beak

Beak geometry (all px) — web `componentSizes.*Beak*`.

| Method | Description |
| --- | --- |
| `fn tooltip(side: BeakSide, align: BeakAlign) -> Self` | Tooltip beak: 16×8, tip radius 2, insets `sizeMedium`. |
| `fn popover(side: BeakSide, align: BeakAlign) -> Self` | Popover beak: 24×12, tip radius 4, insets 34 / 30. |
| `fn with_center(mut self, center: f32) -> Self` | Point the beak at `center` (distance along the edge from the start). |

### BeakSide

Which panel edge carries the beak (opposite of the placement side).

| Variant | Description |
| --- | --- |
| `Top` | Beak on the top edge, pointing up (panel below its trigger). |
| `Bottom` | Beak on the bottom edge, pointing down (panel above its trigger). |
| `Left` | Beak on the left edge, pointing left (panel right of its trigger). |
| `Right` | Beak on the right edge, pointing right (panel left of its trigger). |

### BeakAlign

Where the beak sits along its edge — web `FloatingBeakAlign`.

| Variant | Description |
| --- | --- |
| `Start` | `insetStart + width/2` from the start corner. |
| `Center` | Centered on the edge. |
| `End` | `insetEnd + width/2` from the end corner. |
