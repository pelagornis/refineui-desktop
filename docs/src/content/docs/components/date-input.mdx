Field that opens a Calendar popover — one date or a range (web `DateInput`).

<Screenshot id="date-input" alt="Date Input variants and states" />

## Usage

- Values are `Date`; the field shows them like `Intl` short dates ("Nov 10, 2026").
- The popover holds the same Calendar as the standalone one, header included. The month / year Select lists open as their own top layer above the popover (like the web, where `SelectPortal` puts the list in `body` at `z-popup` after the popover), so the days never show through and the list's blur samples the finished popover; picking a year from a part of the list that overhangs the popover keeps the popover open.
- The trigger is the Input shell at the same `ControlSize` (default `Large`, 52px tall, like the web), so a Date Input lines up with an Input or another Date Input of the same width. Without `full_width` it hugs its text; the gallery uses 325px fields, the web demo width.
- Put it in a `Field` for a label, hint or error; fields side by side keep their labels on one line.
- Like the web, picking a date keeps the calendar open; a click outside (or on the field) closes it. `DateInput::range` opens the two-month range calendar.
- `week_starts_on(1)` starts the calendar on Monday.

```rust
use refineui::prelude::*;

Field::new().label("Due date").control(
    DateInput::new("due", self.due)
        .full_width(true)
        .on_change(cx.listener(|this, d: &Date, _, cx| {
            this.due = Some(*d);
            cx.notify();
        })),
);
```

Open the live, interactive version in the gallery:

```sh
cargo run -p refineui-gallery -- --story date-input
```

## Motion

The popover fades and slides 6px down over `duration-fast` (emphasized); the border and focus halo tween over `duration-fast`.
