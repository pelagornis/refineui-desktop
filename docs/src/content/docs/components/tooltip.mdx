Hover hint with an optional shortcut, anchored to the trigger (not the pointer).

<Screenshot id="tooltip" alt="Tooltip variants and states" />

## Usage

- Wrap a trigger with `Tooltip::new(id, text).child(...)`. `Button` and `Toggle` also have a `.tooltip(text)` shorthand. The bubble is centered on the requested side of the control and stays put while the pointer moves inside it.
- Prefer a side with `.placement(AnchorSide::Top)` (Above) / `Bottom` / `Left` / `Right`; the default is `Bottom`. When that side does not fit in the window, the tooltip flips. `Button::tooltip_placement(..)` sets the same preference for the Button shorthand.
- `.shortcut("⌘S")` adds a keyboard hint; `.action("app::Save")` reads it from the installed keymap instead (no hint when the action is unbound).
- The bubble is painted on the Tooltip layer, so an Above placement is never hidden behind its button.

```rust
use refineui::prelude::*;

Tooltip::new("save-tip", "Save")
    .shortcut("⌘S")
    .placement(AnchorSide::Top)
    .child(Button::new("save", "Save"));
```

Open the live, interactive version in the gallery:

```sh
cargo run -p refineui-gallery -- --story tooltip
```

## Motion

Fades in and slides 6px away from the trigger over `duration-fast` (emphasized); the beak is part of the bubble outline and stays aimed at the trigger center.

## API

Source: [`crates/refineui/src/components/tooltip.rs`](https://github.com/pelagornis/refineui-desktop/blob/main/crates/refineui/src/components/tooltip.rs)

### Tooltip

A tooltip attached to a trigger child.

| Method | Description |
| --- | --- |
| `fn new(id: impl Into<ElementId>, text: impl Into<SharedString>) -> Self` | Attach a hover tooltip to a following `Self::child`. |
| `fn shortcut(mut self, shortcut: impl Into<SharedString>) -> Self` | Tooltip with a keyboard shortcut hint, e.g. `Tooltip::new("save-tip", "Save").shortcut("⌘S")`. |
| `fn action(mut self, action: impl Into<SharedString>) -> Self` | Resolve the shortcut from the installed keymap for this action (`⇧⌘P` / `Ctrl+Shift+P`); no hint when unbound. |
| `fn placement(mut self, side: AnchorSide) -> Self` | Preferred side (web `position`). Defaults to `AnchorSide::Bottom`. Flips when that side does not fit in the window. |
| `fn align(mut self, align: AnchorAlign) -> Self` | Alignment along the facing edge. Defaults to `AnchorAlign::Center`. |
| `fn side_offset(mut self, offset: f32) -> Self` | Gap between the trigger and the panel (beak height is already reserved by the default). `0` is allowed. |
| `fn delay(mut self, delay: Duration) -> Self` | Hover delay before the tooltip appears (web default 120ms). |
| `fn open(mut self, open: bool) -> Self` | Force the tooltip open or closed, skipping hover. Used by docs / screenshots so every side can be captured without a pointer. |
| `fn child(mut self, trigger: impl IntoElement) -> Self` | The control the tooltip is anchored to. |
| `fn bubble(text: impl Into<SharedString>, cx: &App) -> gpui::Div` | Render a static tooltip bubble (used by docs / screenshots). |

### AnchorSide

Placement side for a beaked floating panel (Popover / Tooltip).

| Variant | Description |
| --- | --- |
| `Top` | Above the trigger; the beak sits on the panel's bottom edge. |
| `Bottom` | Below the trigger; the beak sits on the panel's top edge. |
| `Left` | Leading side of the trigger; the beak sits on the panel's right edge. |
| `Right` | Trailing side of the trigger; the beak sits on the panel's left edge. |

| Method | Description |
| --- | --- |
| `fn opposite(self) -> Self` | The opposite side. |
| `fn vertical(self) -> bool` | `true` when the panel is above or below the trigger. |

### AnchorAlign

Start / middle / end alignment of a panel against its trigger.

| Variant | Description |
| --- | --- |
| `Start` | Panel start edge flush with the trigger start edge. |
| `Center` | Centers the panel on the trigger (and aims the beak at the midpoint). |
| `End` | Panel end edge flush with the trigger end edge. |

### AnchoredLayout

Result of `place_anchored`: a clamped panel rect and the beak center along the edge that faces the trigger.

### PlacementViewport

| Method | Description |
