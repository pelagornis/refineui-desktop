A trigger that opens a Menu below it (web `Dropdown`). Real backdrop blur with the `material` feature.

<Screenshot id="dropdown" alt="Dropdown variants and states" />

## Usage

- `align_end()` aligns the menu with the trigger end edge.

```rust
use refineui::prelude::*;

DropdownMenu::new(
    "file",
    Button::new("file-btn", "File").icon_end(IconName::ChevronDown),
    Menu::new("file-menu").item(MenuItem::new("New")).divider().item(MenuItem::new("Open…")),
);
```

Open the live, interactive version in the gallery:

```sh
cargo run -p refineui-gallery -- --story dropdown
```

A trigger that opens a `Menu` below it.

| Method | Description |
| --- | --- |
| `fn new(id: impl Into<ElementId>, trigger: impl IntoElement, menu: Menu) -> Self` | New dropdown. `trigger` is any element (usually a `crate::Button` with `icon_end(ChevronDown)`). |
| `fn align_end(mut self) -> Self` | Align the menu's right edge with the trigger. |
