## Usage

- `Textarea::new(cx)` returns a multi-line `TextInput`; Enter inserts a newline.
- Body text is `bodyMd`, the shell is `roundedLarge` with an 80px minimum height.

```rust
use refineui::prelude::*;

let notes = cx.new(|cx| Textarea::new(cx).placeholder("Write a message…"));

// in render():
div().w(px(320.)).child(self.notes.clone())
```

Open the live, interactive version in the gallery:

```sh
cargo run -p refineui-gallery -- --story textarea
```

## Motion

Border and focus halo tween over `duration-fast`.
