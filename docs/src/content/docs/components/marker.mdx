Timeline marker — inline or as a divider — with an optional live pulse (web `Marker`).

<Screenshot id="marker" alt="Marker variants and states" />

## Usage


```rust
use refineui::prelude::*;

Marker::new("today", "Today").variant(MarkerVariant::Divider);
Marker::new("live", "Live").status(true);
```

Open the live, interactive version in the gallery:

```sh
cargo run -p refineui-gallery -- --story marker
```

## Motion

The status dot pulses like Skeleton (1.5s).

### MarkerVariant

Marker layout (web `MarkerVariant`).

| Variant | Description |
| --- | --- |
| `Default` | Icon + text. |
| `Divider` | Text centered between two rules. |
