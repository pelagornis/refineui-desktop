Sitemap groups and a social | brand | locale meta row (web `Footer`).

<Screenshot id="footer" alt="Footer variants and states" />

## Usage


```rust
use refineui::prelude::*;

Footer::new("footer")
    .group(FooterGroup::new("Product", ["Components", "Tokens"]))
    .brand(None, "RefineUI", Some("© 2026 Pelagornis".into()))
    .social([IconName::Mail, IconName::Link]);
```

Open the live, interactive version in the gallery:

```sh
cargo run -p refineui-gallery -- --story footer
```

## API

Source: [`crates/refineui/src/components/footer.rs`](https://github.com/pelagornis/refineui-gpui/blob/main/crates/refineui/src/components/footer.rs)

### Footer

Site / app footer.

| Method | Description |
| --- | --- |
| `fn new(id: impl Into<ElementId>) -> Self` | Empty footer. |
| `fn group(mut self, g: FooterGroup) -> Self` | Add a sitemap group. |
| `fn brand(mut self, logo: Option<AnyElement>, name: impl Into<SharedString>, description: Option<SharedString>) -> Self` | Brand lockup: optional logo, name and description. |
| `fn social(mut self, icons: impl IntoIterator<Item = IconName>) -> Self` | Social glyph links (start of the meta row). |
| `fn end(mut self, el: impl IntoElement) -> Self` | End slot (locale picker, copyright…). |

### FooterGroup

A titled column of links.

| Method | Description |
| --- | --- |
| `fn new(label: impl Into<SharedString>, links: impl IntoIterator<Item = impl Into<SharedString>>) -> Self` | Group titled `label` with `links`. |
