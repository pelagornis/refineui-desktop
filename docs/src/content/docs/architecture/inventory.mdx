Status: **exists** = ready as is (contract may still list planned states); **adapt** = built on an existing component that needs desktop work; **new** = not built yet; **optional** = kept behind the `web-extras` feature. Phases follow the [phase plan](/architecture/overview/#phase-plan).

Components that exist today but are not named in the brief stay in Desktop Core: Breadcrumb (becomes a path bar), Bubble, Message, Calendar, Date and Time Input, Input OTP, Card, Chart, Code Block, Marker, Pagination, Progress Stepper, Stepper, Segmented Control, Sidebar (becomes a navigation Panel), Text and Icon. Each has a contract.
