## Preserved from web (`refineui-foundation`)

Color (palette + 69 semantic aliases from the web pairs, plus `surfaceOverlay` and `surfaceFrosted`; light/dark), typography (16 styles,
21 roles), spacing, sizing (`componentSizes`, icon sizes), radius, border
(`stroke`), elevation (`shadow` / `Elevation`), opacity, motion (durations,
easings, distances), blur (`blur`, `blur::role`). `scripts/sync_tokens.py`
keeps colors in sync with the web `@refineui/tokens` source. The other
values are checked against the web package by the token audit.

## Extended / redesigned

| Concern | Desktop decision |
| --- | --- |
| Layout | Split views, docks and panels replace responsive breakpoints. Size constraints come from `DesktopMetrics` and per-panel min/max sizes. The page `container()` is optional (`web-extras`). |
| Z-index / layers | `z_index::DESKTOP_ORDER`: content < sticky < floating panel < overlay < popup < messages < tooltip < drag preview < debug. GPUI has no z-index; `foundation::LayerOrder::priority()` feeds `layer(..).priority(..)`. |

## Introduced

| Concern | Where | Notes |
| --- | --- | --- |
| Density | `Density::{Compact, Comfortable, Spacious}`, `Density::desktop()` | See [Density](/architecture/density/). |
| Focus | `Theme::focus_ring`, `interaction::focus` | 2px `borderFocus` ring on keyboard focus only. Regions cycle with F6. |
| Keyboard | `interaction::keymap` | Contexts, conflicts, platform labels. |
| Interaction states | `contracts::InteractionState` | Default, hovered, pressed, focused, disabled, loading, selected, dragging. |
| Window metrics | `refineui_foundation::window`, `platform` | Titlebar heights, controls, resize hit areas, minimum window size. |
| Pointer and cursor | `foundation::CursorRole` | Desktop convention: arrow on buttons, hand only on links. |
| Scroll behaviour | `ScrollArea`, `platform::ScrollbarStyle` | The platform adapter picks the scrollbar style: overlay on macOS, always visible on Windows. |
| Selection | `interaction::selection` | See [Interaction model](/architecture/interaction/). |
| Drag and drop | `interaction::dnd` | Drop edges, dock zones, reorder. |
| Accessibility | contracts `a11y_role`, focus rules | GPUI 0.2.2 has no accessibility tree, so roles are recorded in the contracts and keyboard / focus rules are enforced by tests. |

## Material tokens

`refineui_foundation::material` defines the material roles used by the
Material Engine (`refineui-material`). Each `MaterialTokens` value carries
blur radius, saturation, tint, edge highlight, border, grain (noise),
reflection and specular strength (glass only), elevation and an opaque **fallback** fill for renderers without blur or
with reduced transparency.

| Role | Blur | Use |
| --- | --- | --- |
| `Thin` | 12 px | Tooltips, light overlays |
| `Regular` | 16 px | Menus, popovers, dropdowns |
| `Thick` | 28 px | Sheets, large floating panels |
| `Chrome` | 24 px | Titlebars, sidebars over content |
| `Glass` | 18 px | Expressive glass: low tint, saturation 1.9, lit edges, reflection band, specular spot, grain |
| `Scrim` | 2 px | Modal backdrops (matches the web dialog blur) |

`MaterialRole::tokens(mode)` returns the light or dark variant. See
[Material Engine](/architecture/material/) for the renderer.
