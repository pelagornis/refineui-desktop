## Building blocks

| Component | Role |
| --- | --- |
| [Split View](/workspace/split-view/) | Two or more panes along an axis, separated by resize handles. Ratios are fractions; each pane has a minimum size. |
| [Panel Group](/workspace/panel-group/) | `Panel`s in one dock slot, as tabs (`PanelGroupMode::Tabs`) or stacked collapsible headers (`Stack`). |
| [Dock Area](/workspace/dock-area/) | The center plus left, right and bottom `Dock`s. Each dock holds a panel group, is resizable within its limits, can be zoomed and accepts panel drops. |
| [Tab Group](/workspace/tab-group/) | Documents in one pane: a `TabBar` of `DocumentTab`s (dirty dot, pinned, preview, close button on hover *and* on focus / active) plus content. |
| [Inspector](/workspace/inspector/) | A property grid of collapsible `InspectorSection`s for the right dock. |
| [Floating Panel](/workspace/floating-panel/) | A tool window with its own titlebar: `FloatingPanelFrame` inside a window, or `open_floating_panel` for a separate OS window (blurred background on macOS). |
| Editor | The center content for a document type comes from the app; RefineUI supplies the chrome around it. |

## Layout state vs transient state

```text
App state (persisted, serde)          Component state (transient)
──────────────────────────────        ──────────────────────────────
WorkspaceLayout                        hover / pressed plates
 ├ center: PaneNode                    drag in flight, drop indicator
 │   ├ Split { axis, children, ratios} splitter being dragged
 │   └ Tabs(TabGroupState)             scroll offsets
 ├ docks: left / right / bottom        animation progress
 │   DockState { visible, size,
 │               panels, active }
 ├ floating: [FloatingPanelState]
 └ active_group
```

`refineui::workspace::layout` implements the left column today. It is
serializable with the `serde` feature and carries a `version`.
`WorkspaceLayout::normalize()` repairs whatever a stale file left behind:
NaN or zero ratios, empty splits, nested same-axis splits, out-of-range
active indices, negative dock sizes and a missing active group. Mutations
cover tabs (`open`, `promote`, `close_tab`, `close_others`,
`close_to_right`, `close_all`, `set_pinned`, `move_tab`), splits (`split`,
`split_with`, `set_ratios`, `close_group`), docks (`toggle_dock`,
`set_dock_size`, `move_panel`, `activate_panel`), floating panels
(`float_panel`, `set_floating_bounds`) and zoom (`toggle_zoom`); structural mutations re-run `normalize()`.

## Guidelines for apps

- **User arrangements win.** Keep the user's dock sizes and restore them
  when the window grows again; shrink docks only when the center would go
  below its minimum.
- **Persistence.** Save the layout on change (debounced) and on window
  close; restore it before the first frame.
- **Docking by drag.** Dropping a tab or panel on a pane uses
  `dnd::dock_zone`: the center zone joins the tab group, an edge zone
  splits.
- **Keyboard.** Moving focus between panes, moving tabs, toggling docks
  and resizing a focused splitter (arrows) can all be bound through the keymap.
