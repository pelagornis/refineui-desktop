One `AppMenu` model for the system menu bar on macOS and an in-window menu bar on Windows and Linux.

<Screenshot id="menu-bar" alt="Menu Bar variants and states" />

## Usage

- Items name GPUI actions (`"editor::Save"`); shortcuts are read from the installed keymap, so the menu, tooltips and command items always agree.
- `set_system_menus(&menus, cx)` builds `gpui::Menu`s with key equivalents and standard `OsAction`s (Undo, Redo, Cut, Copy, Paste, Select All) and returns any unregistered action names.
- In-window, the bar is a horizontal `ButtonGroup` row of ghost small `Button`s; the open menu's button is `selected`.
- Click a title or press **F10** / **Alt**; ← / → move between menus, ↓ / Enter open, Escape closes and returns focus. While one menu is open, hovering another title switches to it.

```rust
use refineui::prelude::*;

let menus = vec![
    AppMenu::new("File").action("New File", "demo::NewFile").separator().action("Save", "demo::Save"),
    AppMenu::new("Edit").action("Undo", "demo::Undo").action("Copy", "demo::Copy"),
];
if Os::current() == Os::MacOs {
    set_system_menus(&menus, cx);
}
MenuBar::new("menubar", menus);
```

Open the live, interactive version in the gallery:

```sh
cargo run -p refineui-gallery -- --story menu-bar
```

## Motion

Menus open instantly; hover-switching between open menus is immediate, like native menu bars. Title buttons use the Button hover / press motion.

## API

Source: [`crates/refineui/src/shell/menu_bar.rs`](https://github.com/pelagornis/refineui-desktop/blob/main/crates/refineui/src/shell/menu_bar.rs)

### MenuBar

In-window menu bar.

| Method | Description |
| --- | --- |
| `fn new(id: impl Into<ElementId>, menus: Vec<AppMenu>) -> Self` | Menu bar showing `menus`. |
| `fn bind_keys(cx: &mut App)` | Bind F10 to `FocusMenuBar` (Windows / Linux convention). |

### AppMenu

A top-level menu ("File", "Edit", …).

| Method | Description |
| --- | --- |
| `fn new(name: impl Into<SharedString>) -> Self` | Empty menu titled `name`. |
| `fn action(mut self, label: impl Into<SharedString>, action: impl Into<SharedString>) -> Self` | Add an action item. |
| `fn separator(mut self) -> Self` | Add a separator. |
| `fn submenu(mut self, menu: AppMenu) -> Self` | Add a submenu. |
| `fn actions(&self) -> Vec<SharedString>` | Every action name in this menu (recursively). |

### AppMenuItem

One entry of an `AppMenu`.

| Variant | Description |
| --- | --- |
| `Action { .. }` | Runs a GPUI action by name. |
| `Separator` | Separator line. |
| `Submenu(AppMenu)` | Nested menu. |

### Functions

| Function | Description |
| --- | --- |
| `fn os_action_for(label: &str) -> Option<OsAction>` | The system action for a standard edit item, by label. |
| `fn system_menus(menus: &[AppMenu], cx: &App) -> (Vec<gpui::Menu>, Vec<SharedString>)` | GPUI menus for `menus`, plus the action names that are not registered (those items are left out). |
| `fn set_system_menus(menus: &[AppMenu], cx: &mut App) -> Vec<SharedString>` | Install `menus` as the system menu bar (macOS; elsewhere GPUI keeps them for `cx.get_menus()`). Returns unregistered action names. |
| `fn focus_menu_bar(window: &mut Window, cx: &mut App)` | Dispatch `FocusMenuBar` (for apps that bind Alt alone themselves). The `crate::shell::ApplicationShell` handles it from anywhere in the window. |
