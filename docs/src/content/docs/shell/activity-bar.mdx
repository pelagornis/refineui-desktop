A vertical rail of views (Explorer, Search, Source Control …) — RefineUI style by default, fully restylable: shape, size, indicator, colours, labels, custom faces.

<Screenshot id="activity-bar" alt="Activity Bar variants and states" />

## Usage

- **Refine** (default) — density-sized bar (48px comfortable), 36px rounded tiles, the selected item sits on a `backgroundSurfaceSelected` plate; tooltips name each item.
- **Navigation rail** — 80px, captions under the icons (`LabelMode::Below`). **Expanded** — `expanded(true)` shows labels beside the icons at `expanded_width`.
- **Rail preset** — `ActivityBar::rail` keeps the former Side Dock look (circle → squircle morph, edge pill, brand fill) for chat-style apps.
- Every knob is on `ActivityBarStyle`: `shape` (Rounded / Square / Circle / Morph), `indicator` (None / Bar / Dot / Plate), `item_size`, `gap`, `icon`, `border` and every colour. `render_item` draws the face yourself; the bar keeps hit-testing, focus, indicator and tooltip.
- Items: `icon`, `image`, `initials` (+`tint`), `folder`; `badge(n)`, `dot()`, `unread`, `disabled`, `action` (shows the keymap shortcut in the tooltip). `header` / `footer` slots and `footer_item`s pin to the ends.
- Keyboard: the bar is one tab stop; ↑ / ↓ move, Enter / Space activate, **⌥↑ / ⌥↓** reorder when `on_reorder` is set (drag also reorders, with a drop indicator).

```rust
use refineui::prelude::*;

ActivityBar::new("activity")
    .items([
        ActivityItem::icon("explorer", "Explorer", IconName::Document),
        ActivityItem::icon("search", "Search", IconName::Search).action("workspace::Find"),
        ActivityItem::icon("git", "Source Control", IconName::Git).badge(3),
    ])
    .footer_item(ActivityItem::icon("settings", "Settings", IconName::Settings))
    .indicator(IndicatorStyle::Bar)
    .shape(ItemShape::Rounded(8.))
    .selected(self.view.clone())
    .on_select(cx.listener(|this, id: &SharedString, _, cx| { this.view = id.clone(); cx.notify(); }))
    .on_reorder(move |from, to, _window, cx| {
        // `to` is the final index: items.remove(from); items.insert(to, item)
    });
```

Open the live, interactive version in the gallery:

```sh
cargo run -p refineui-gallery -- --story activity-bar
```

## Motion

Item fill, ink and the indicator tween over `duration-fast`; `ItemShape::Morph` tiles round → squircle over `duration-fast`; the bar indicator grows over `duration-medium` (emphasized); tooltips fade and slide 6px over `duration-fast`.

## API

Source: [`crates/refineui/src/shell/activity_bar.rs`](https://github.com/pelagornis/refineui-gpui/blob/main/crates/refineui/src/shell/activity_bar.rs)

### ActivityBar

The bar. See the module docs.

| Method | Description |
| --- | --- |
| `fn new(id: impl Into<ElementId>) -> Self` | Bar with the default (Refine) look. |
| `fn rail(id: impl Into<ElementId>) -> Self` | Bar with the former Side Dock look. |
| `fn navigation_rail(id: impl Into<ElementId>) -> Self` | Labelled navigation rail. |
| `fn style(mut self, style: ActivityBarStyle) -> Self` | Whole style. |
| `fn preset(self, preset: ActivityBarPreset) -> Self` | Preset. |
| `fn restyle(mut self, f: impl FnOnce(&mut ActivityBarStyle)) -> Self` | Edit the style in place: `.restyle(\|s\| s.badge = Some(red))`. |
| `fn shape(mut self, shape: ItemShape) -> Self` | Item shape. |
| `fn indicator(mut self, indicator: IndicatorStyle) -> Self` | Indicator. |
| `fn item_size(mut self, size: f32) -> Self` | Item size. |
| `fn labels(mut self, mode: LabelMode) -> Self` | Label mode. |
| `fn expanded(mut self, expanded: bool) -> Self` | Expanded (labels beside icons) or collapsed (tooltips). |
| `fn side(mut self, side: BarSide) -> Self` | Docked edge. |
| `fn header(mut self, e: impl IntoElement) -> Self` | Element above the items (logo, workspace switcher). |
| `fn footer(mut self, e: impl IntoElement) -> Self` | Element below the pinned footer items (account, sync state). |
| `fn item(mut self, item: ActivityItem) -> Self` | Add an item. |
| `fn items(mut self, items: impl IntoIterator<Item = ActivityItem>) -> Self` | Add items. |
| `fn divider(mut self) -> Self` | Divider between groups. |
| `fn footer_item(mut self, item: ActivityItem) -> Self` | Item pinned to the bottom (Settings, Accounts). |
| `fn selected(mut self, id: impl Into<SharedString>) -> Self` | Selected item id. |
| `fn on_select(mut self, f: impl Fn(&SharedString, &mut Window, &mut App) + 'static) -> Self` | Activation handler. |
| `fn on_reorder(mut self, f: impl Fn(usize, usize, &mut Window, &mut App) + 'static) -> Self` | Enable drag-to-reorder of the main items: `f(from, to)` with indices into the main item list (dividers excluded; `to` is the final index after removal, as `crate::interaction::dnd::reorder`). |
| `fn render_item(mut self, f: impl Fn(&ActivityItem, ActivityItemState, &mut Window, &mut App) -> AnyElement + 'static) -> Self` | Draw every item face yourself (the bar keeps hit-testing, focus, indicator and tooltip). |
| `fn fill(mut self, fill: bool) -> Self` | Fill the parent's height (default) or hug the content. |

### ActivityItem

One destination.

| Method | Description |
| --- | --- |
| `fn icon(id: impl Into<SharedString>, label: impl Into<SharedString>, icon: IconName) -> Self` | Icon item. |
| `fn image(id: impl Into<SharedString>, label: impl Into<SharedString>, src: impl Into<ImageSource>) -> Self` | Picture item (avatar / workspace logo). |
| `fn initials(id: impl Into<SharedString>, label: impl Into<SharedString>) -> Self` | Initials item (up to three letters of the label). |
| `fn tint(mut self, color: AvatarColor) -> Self` | Tint an initials item. |
| `fn folder(id: impl Into<SharedString>, label: impl Into<SharedString>, members: impl IntoIterator<Item = ActivityItem>) -> Self` | Group of items shown as a two-item cluster. |
| `fn badge(mut self, count: u32) -> Self` | Count badge (`0` hides it). |
| `fn dot(mut self) -> Self` | Dot badge. |
| `fn unread(mut self, unread: bool) -> Self` | Unread mark (indicator-dependent: short bar / muted dot). |
| `fn disabled(mut self, disabled: bool) -> Self` | Disabled (skipped by the keyboard, no activation). |
| `fn action(mut self, action: impl Into<SharedString>) -> Self` | The GPUI action this item mirrors — its shortcut shows in the tooltip. |
| `fn id(&self) -> &SharedString` | Id. |
| `fn label(&self) -> &SharedString` | Label. |
| `fn icon_name(&self) -> Option<IconName>` | Icon, for icon items. |

### ActivityBarStyle

The complete look of an `ActivityBar`; `None` colours resolve from the theme.

### ActivityBarPreset

Preset shorthands.

| Variant | Description |
| --- | --- |
| `Refine` | `ActivityBarStyle::refine`. |
| `Rail` | `ActivityBarStyle::rail`. |
| `NavigationRail` | `ActivityBarStyle::navigation_rail`. |

### ItemShape

Item corner shape.

| Variant | Description |
| --- | --- |
| `Rounded(f32)` | Rounded square with this radius. |
| `Square` | Sharp square. |
| `Circle` | Circle. |
| `Morph` | Circle at rest, `roundedXXLarge` square when hovered / selected (the Rail preset). |

### IndicatorStyle

Selection indicator.

| Variant | Description |
| --- | --- |
| `None` | No indicator (pair with a selected colour). |
| `Bar` | Bar on the docked edge (grows on hover / select; a short mark for unread items). |
| `Dot` | Dot under the icon (selected: ink, unread: muted). |
| `Plate` | Filled plate behind the selected item. |

### LabelMode

How item names show.

| Variant | Description |
| --- | --- |
| `Tooltip` | Tooltip beside the item (icon-only bar). |
| `Below` | Caption under each icon (navigation rail). |
| `Beside` | Label beside the icon in a wider bar (expanded). |

### BarSide

Which window edge the bar is docked to.

| Variant | Description |
| --- | --- |
| `Leading` | Leading (left) edge. |
| `Trailing` | Trailing (right) edge. |

### ActivityItemState

State passed to a custom item renderer.

### ItemBadge

Badge on an item.

| Variant | Description |
| --- | --- |
| `Count(u32)` | Count (`99+` above 99). |
| `Dot` | Small dot. |
