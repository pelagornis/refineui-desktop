## Usage

- There is a single look — no presets or variants: density-sized bar (48px comfortable), rounded tiles that morph toward a squircle when selected, a `backgroundBrandSubtle` selected plate with `foregroundBrand` ink and a brand bar indicator on the edge. Tooltips name each item.
- Items: `icon`, `image` (external URL, asset, or bytes), `folder`; `badge(n)`, `dot()`, `unread`, `disabled`, `action` (shows the keymap shortcut in the tooltip). `header` / `footer` slots and `footer_item`s pin to the ends. `render_item` draws a custom face; the bar keeps hit-testing, focus, indicator and tooltip.
- **Folders** — `ActivityItem::folder` groups items in a Toolbar-style tube (hairline `borderDefault`, `backgroundBrandSubtle`, `XXX_SMALL` padding, radius = tile radius + pad). A closed folder shows a 2×2 stacked preview of up to four members and a count badge when there are more than four (unless the item already has a badge). An open folder shows the FolderOpen icon; members sit inside the same plate, which grows and shrinks with accordion height motion (`default_open(true)` seeds the first frame).
- Keyboard: the bar is one tab stop; ↑ / ↓ move (open-folder children are in the order), Enter / Space activate and also toggle a focused folder, **⌥↑ / ⌥↓** reorder main items when `on_reorder` is set (folder children are skipped; drag also reorders, with a drop indicator).

```rust
use refineui::prelude::*;

ActivityBar::new("activity")
    .items([
        ActivityItem::icon("explorer", "Explorer", IconName::Document),
        ActivityItem::icon("search", "Search", IconName::Search).action("workspace::Find"),
        ActivityItem::icon("git", "Source Control", IconName::Git).badge(3),
        ActivityItem::folder("apps", "Apps", [
            ActivityItem::icon("mail", "Mail", IconName::Mail),
            ActivityItem::icon("photo", "Photos", IconName::Grid),
        ]),
        ActivityItem::folder("projects", "Projects", [
            ActivityItem::icon("docs", "Docs", IconName::Document),
        ]).default_open(true),
        ActivityItem::image("workspace", "Workspace", workspace_logo),
    ])
    .footer_item(ActivityItem::icon("settings", "Settings", IconName::Settings))
    .selected(self.view.clone())
    .on_select(cx.listener(|this, id: &SharedString, _, cx| { this.view = id.clone(); cx.notify(); }))
    .on_reorder(move |from, to, _window, cx| {
        // `to` is the final index: items.remove(from); items.insert(to, item)
    });
```

```sh
cargo run -p refineui-gallery -- --story activity-bar
```

## Motion

Folders expand and collapse with accordion height motion (`ACCORDION_PANEL` / `ACCORDION_CONTENT`); the group tube grows with the members, and the tile switches from a 2×2 member preview to the FolderOpen icon over `Motion::CHEVRON`. Item fill, ink and the indicator tween over `duration-fast`; tiles morph round → squircle over `duration-fast`; the bar indicator grows over `duration-medium` (emphasized); tooltips fade and slide 6px over `duration-fast`.

## API

Source: [`crates/refineui/src/shell/activity_bar.rs`](https://github.com/pelagornis/refineui-gpui/blob/main/crates/refineui/src/shell/activity_bar.rs)

### ActivityBar

The bar. See the module docs.

| Method | Description |
| --- | --- |
| `fn new(id: impl Into<ElementId>) -> Self` | New bar (collapsed). |
| `fn side(mut self, side: BarSide) -> Self` | Docked edge. |
| `fn header(mut self, e: impl IntoElement) -> Self` | Element above the items (logo, workspace switcher). |
| `fn footer(mut self, e: impl IntoElement) -> Self` | Element below the pinned footer items (account, sync state). |
| `fn item(mut self, item: ActivityItem) -> Self` | Add an item. |
| `fn items(mut self, items: impl IntoIterator<Item = ActivityItem>) -> Self` | Add items. |
| `fn divider(mut self) -> Self` | Divider between groups. |
| `fn footer_item(mut self, item: ActivityItem) -> Self` | Item pinned to the bottom (Settings, Accounts). |
| `fn selected(mut self, id: impl Into<SharedString>) -> Self` | Selected item id. |
| `fn on_select(mut self, f: impl Fn(&SharedString, &mut Window, &mut App) + 'static) -> Self` | Activation handler. |
| `fn on_reorder(mut self, f: impl Fn(usize, usize, &mut Window, &mut App) + 'static) -> Self` | Enable drag-to-reorder of the main items: `f(from, to)` with indices into the main item list (dividers excluded; `to` is the final index after removal, as `crate::interaction::dnd::reorder`). |
| `fn render_item(mut self, f: impl Fn(&ActivityItem, ActivityItemState, &mut Window, &mut App) -> AnyElement + 'static) -> Self` | Draw every item face yourself (the bar keeps hit-testing, focus, indicator and tooltip). |
| `fn fill(mut self, fill: bool) -> Self` | Fill the parent's height (default) or hug the content. |

### ActivityItem

One destination.

| Method | Description |
| --- | --- |
| `fn icon(id: impl Into<SharedString>, label: impl Into<SharedString>, icon: IconName) -> Self` | Icon item. |
| `fn image(id: impl Into<SharedString>, label: impl Into<SharedString>, src: impl Into<ImageSource>) -> Self` | Picture item from an external image source (URL, asset, or bytes). |
| `fn folder(id: impl Into<SharedString>, label: impl Into<SharedString>, members: impl IntoIterator<Item = ActivityItem>) -> Self` | Folder of items. Clicking the tile expands or collapses the members inside a shared Toolbar-style tube. Closed, the tile shows a 2×2 stacked preview of the members; open, it shows the FolderOpen icon. |
| `fn default_open(mut self, open: bool) -> Self` | Open this folder on first show (folders only). |
| `fn badge(mut self, count: u32) -> Self` | Count badge (`0` hides it). |
| `fn dot(mut self) -> Self` | Dot badge. |
| `fn unread(mut self, unread: bool) -> Self` | Unread mark (indicator-dependent: short bar / muted dot). |
| `fn disabled(mut self, disabled: bool) -> Self` | Disabled (skipped by the keyboard, no activation). |
| `fn action(mut self, action: impl Into<SharedString>) -> Self` | The GPUI action this item mirrors — its shortcut shows in the tooltip. |
| `fn id(&self) -> &SharedString` | Id. |
| `fn label(&self) -> &SharedString` | Label. |
| `fn icon_name(&self) -> Option<IconName>` | Icon, for icon items. |

### BarSide

Which window edge the bar is docked to.

| Variant | Description |
| --- | --- |
| `Leading` | Leading (left) edge. |
| `Trailing` | Trailing (right) edge. |

### ActivityItemState

State passed to a custom item renderer.

### ItemBadge

Badge on an item.

| Variant | Description |
| --- | --- |
| `Count(u32)` | Count (`99+` above 99). |
| `Dot` | Small dot. |
