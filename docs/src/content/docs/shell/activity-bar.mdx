The top-level destinations of a window (Explorer, Search, Source Control, Mail …) as one icon bar, an expanded list or a horizontal strip, in RefineUI style.

## Usage

- One neutral, desktop-tool look: every item is the same density hit target (`activity_item`, 36px comfortable) with a `roundedLarge` plate and a 20px icon. At rest the plate is clear and the icon `foregroundSecondary`; hover paints `backgroundPrimaryHover`, press `backgroundPrimaryActive`; the selected item gets `backgroundSurfaceSelected` with `foregroundPrimary` ink. The bar is `backgroundPrimary` (Sidebar chrome material) with a hairline `borderSubtle` on its inner edge. Keyboard focus draws `focusRing` around the plate.
- **Indicator** — `ActiveIndicator::Edge` (default) adds a 2px `backgroundBrand` line, 20px long, on the bar's outer edge (bottom edge of a horizontal bar); `ActiveIndicator::Plate` uses the selected plate alone. A closed folder that holds the selection lights up instead of its hidden child.
- **Labels** — `ActivityLabels::Tooltip` (default) is icon-only with a `Tooltip` placed away from the docked edge (Right for a leading bar), showing the item's `tooltip` text or label and the `action` shortcut. `Below` adds a caption under the icon (72px bar). `Beside` / `expanded(true)` is a list with labels, trailing badges and folder chevrons (`expanded_width`, 200px); the width animates over `duration-medium`.
- **Badges** — `badge(n)` (count) or `dot()`; `badge_variant(BadgeVariant::…)` picks brand (default), neutral or a status colour. In icon-only and caption bars the count is a compact corner pill (14px, 9px digits) up and to the right of the icon's corner, so it covers only the icon's corner and grows to the left; it may overhang the item by up to 4px into the bar's own padding (`badge_offset`, `CORNER_BADGE_OVERHANG`) but never crosses the bar border, the indicator or a folder outline. A 2px ring in the colour behind it (plate, folder group or bar) separates it from the icon. Corner pills spell out at most `ActivityBar::corner_badge_max` (default 9): 1, 9, then `9+`, and the item's tooltip then reads “Label · 42” (captioned items get a tooltip only then). In an expanded bar the badge moves to the row's trailing edge at full size and reads up to `99+`. `unread(true)` adds a small muted dot on the outer edge; `disabled(true)` dims the item, blocks clicks and is skipped by the arrows.
- **Structure** — `divider()` and `section(title)` split groups (a title shows only in an expanded bar). `footer_item`s stay pinned to the far end and the main list scrolls in a `ScrollArea` with a hidden scrollbar; `header` / `footer` slots take any element. `BarSide::Leading` / `Trailing` dock vertically, `Top` / `Bottom` lay the bar out horizontally.
- **Folders** — `ActivityItem::folder` shows its own icon (`folder_icon`, default Folder / FolderOpen) and rolls up its members' badges (sum of counts, or a dot). Opening it reveals the members on a recessed `backgroundSurfaceHover` group plate with accordion height motion (`default_open(true)` seeds the first frame).
- Keyboard: the bar is one tab stop; arrows follow the orientation (↑ / ↓ vertical, ← / → horizontal) and skip disabled items, Home / End jump to the ends, Enter / Space activate and toggle a focused folder, **⌥+arrow** reorders main items when `on_reorder` is set (drag also reorders, with a drop indicator).
- **Breaking changes (0.x)** — the round-to-squircle tile, the growing edge pill and `bar_heights()` are gone; the bar is no longer `surfaceSunken`; badges default to brand ink instead of always danger; a closed folder no longer shows a 2×2 member preview or a member-count badge; `BarSide` gained `Top` / `Bottom` (exhaustive matches need new arms); `ActivityItemState` gained `pressed` and `disabled`; `badge_offset` takes a `slack` argument and can return negative offsets (corner pills overhang into the bar padding), and corner count badges cap at `9+` by default (`corner_badge_max` to change).

```rust
use refineui::prelude::*;

ActivityBar::new("activity")
    .items([
        ActivityItem::icon("explorer", "Explorer", IconName::Document),
        ActivityItem::icon("search", "Search", IconName::Search).action("workspace::Find"),
        ActivityItem::icon("git", "Source Control", IconName::Git).badge(3),
    ])
    .divider()
    .item(ActivityItem::icon("issues", "Issues", IconName::ErrorCircle)
        .badge(128)
        .badge_variant(BadgeVariant::Danger))
    .item(ActivityItem::folder("projects", "Projects", [
        ActivityItem::icon("board", "Roadmap", IconName::Board),
        ActivityItem::icon("chat", "Design review", IconName::Chat).dot(),
    ]))
    .footer_item(ActivityItem::icon("settings", "Settings", IconName::Settings))
    .expanded(self.sidebar_open) // icon-only with tooltips when false
    .selected(self.view.clone())
    .on_select(cx.listener(|this, id: &SharedString, _, cx| { this.view = id.clone(); cx.notify(); }))
    .on_reorder(move |from, to, _window, cx| {
        // `to` is the final index: items.remove(from); items.insert(to, item)
    });
```

## Motion

Item plate and ink tween over `duration-fast`; the expanded width animates over `duration-medium`; folders expand and collapse with accordion height motion (`ACCORDION_PANEL` / `ACCORDION_CONTENT`) while the group plate fades in; tooltips use the Tooltip motion (fade and 6px slide over `duration-fast`). The active indicator does not move or grow.

## API

### ActivityBar

The bar.

| Method | Description |
| --- | --- |
| `fn new(id: impl Into<ElementId>) -> Self` | New icon-only bar on the leading edge. |
| `fn corner_badge_max(mut self, max: u32) -> Self` | Largest count a corner badge (icon-only and caption bars) spells out before it reads `{max}+` (default 9). Keep it to one or two digits so the badge stays on the icon's corner; the tooltip shows the full count. |
| `fn side(mut self, side: BarSide) -> Self` | Docked edge (`BarSide::Top` / `BarSide::Bottom` are horizontal). |
| `fn labels(mut self, labels: ActivityLabels) -> Self` | How item names show. |
| `fn expanded(self, expanded: bool) -> Self` | Expanded (labels beside the icons) or icon-only with tooltips. |
| `fn expanded_width(mut self, width: f32) -> Self` | Width of the expanded vertical bar (default `ACTIVITY_EXPANDED_WIDTH`). |
| `fn indicator(mut self, indicator: ActiveIndicator) -> Self` | Active-item mark. |
| `fn border(mut self, border: bool) -> Self` | Hairline on the inner edge (default on). |
| `fn header(mut self, e: impl IntoElement) -> Self` | Element before the items (logo, workspace switcher). |
| `fn footer(mut self, e: impl IntoElement) -> Self` | Element after the pinned footer items (account, sync state). |
| `fn item(mut self, item: ActivityItem) -> Self` | Add an item. |
| `fn items(mut self, items: impl IntoIterator<Item = ActivityItem>) -> Self` | Add items. |
| `fn divider(mut self) -> Self` | Divider between groups. |
| `fn section(mut self, title: impl Into<SharedString>) -> Self` | Start a titled group: a divider in an icon-only bar, the title in an expanded one. |
| `fn footer_item(mut self, item: ActivityItem) -> Self` | Item pinned to the end (Settings, Accounts). |
| `fn selected(mut self, id: impl Into<SharedString>) -> Self` | Selected item id. |
| `fn on_select(mut self, f: impl Fn(&SharedString, &mut Window, &mut App) + 'static) -> Self` | Activation handler (click, Enter, Space). |
| `fn on_reorder(mut self, f: impl Fn(usize, usize, &mut Window, &mut App) + 'static) -> Self` | Enable drag-to-reorder of the main items: `f(from, to)` with indices into the main item list (sections excluded; `to` is the final index after removal, as `crate::interaction::dnd::reorder`). |
| `fn render_item(mut self, f: impl Fn(&ActivityItem, ActivityItemState, &mut Window, &mut App) -> AnyElement + 'static) -> Self` | Draw every item face yourself (the bar keeps the plate, hit-testing, focus, indicator, badge and tooltip). |
| `fn fill(mut self, fill: bool) -> Self` | Fill the parent's cross size (default) or hug the content. |

### ActivityItem

One destination.

| Method | Description |
| --- | --- |
| `fn icon(id: impl Into<SharedString>, label: impl Into<SharedString>, icon: IconName) -> Self` | Icon item. |
| `fn image(id: impl Into<SharedString>, label: impl Into<SharedString>, src: impl Into<ImageSource>) -> Self` | Picture item (workspace logo, account): an external image source (URL, asset or bytes) drawn as a 24px rounded square. |
| `fn folder(id: impl Into<SharedString>, label: impl Into<SharedString>, members: impl IntoIterator<Item = ActivityItem>) -> Self` | Folder of items. Clicking it shows or hides the members in a group plate under it. Closed, it shows its icon (`Self::folder_icon`, `Folder` by default) and the sum of its members' badges. |
| `fn folder_icon(mut self, glyph: IconName) -> Self` | Icon of a folder (folders only; open folders show `FolderOpen` when this is the default `Folder`). |
| `fn default_open(mut self, open: bool) -> Self` | Open this folder on first show (folders only). |
| `fn badge(mut self, count: u32) -> Self` | Count badge (`0` hides it). |
| `fn dot(mut self) -> Self` | Dot badge. |
| `fn badge_variant(mut self, variant: BadgeVariant) -> Self` | Badge colour: `Default` (brand ink, the default), `Neutral`, `Success`, `Warning` or `Danger` (`Outline` draws as `Neutral`). |
| `fn unread(mut self, unread: bool) -> Self` | Unread mark: a small muted dot on the bar edge (quieter than a badge). |
| `fn disabled(mut self, disabled: bool) -> Self` | Disabled (dimmed, skipped by the keyboard, no activation). |
| `fn tooltip(mut self, text: impl Into<SharedString>) -> Self` | Tooltip text (defaults to the label). |
| `fn action(mut self, action: impl Into<SharedString>) -> Self` | The GPUI action this item mirrors — its shortcut shows in the tooltip. |
| `fn id(&self) -> &SharedString` | Id. |
| `fn label(&self) -> &SharedString` | Label. |
| `fn icon_name(&self) -> Option<IconName>` | Icon, for icon and folder items. |
| `fn is_folder(&self) -> bool` | Whether this is a folder. |
| `fn displayed_badge(&self) -> Option<ItemBadge>` | The badge drawn on the item: its own badge, or for a folder the sum of its members' count badges (a dot when members only have dots). |

### BarSide

Which window edge the bar is docked to.

| Variant | Description |
| --- | --- |
| `Leading` | Leading (left) edge, vertical. |
| `Trailing` | Trailing (right) edge, vertical. |
| `Top` | Top edge, horizontal (e.g. above a sidebar). |
| `Bottom` | Bottom edge, horizontal. |

### ActivityLabels

How item names show.

| Variant | Description |
| --- | --- |
| `Tooltip` | Icon-only bar; the name shows in a tooltip. |
| `Below` | Caption under each icon (navigation rail). Horizontal bars show the caption beside the icon instead. |
| `Beside` | Label beside the icon in a wider bar. |

### ActiveIndicator

How the active item is marked (on top of its selected plate).

| Variant | Description |
| --- | --- |
| `Edge` | 2px brand line on the bar edge (default). |
| `Plate` | The selected plate only. |

### ActivityItemState

State passed to a custom item renderer.

### ItemBadge

Badge on an item.

| Variant | Description |
| --- | --- |
| `Count(u32)` | Count (`99+` above 99 in a row; corner badges cap at `ActivityBar::corner_badge_max`). |
| `Dot` | Small dot. |

| Method | Description |
| --- | --- |
| `fn text(self) -> Option<SharedString>` | Text of a count badge (`None` for a dot). |
| `fn label(self, max: u32) -> Option<SharedString>` | Text of a count badge capped at `max` (`{max}+` above it). |
| `fn is_capped(self, max: u32) -> bool` | Whether `label(max)` drops digits. |

### Functions

| Function | Description |
| --- | --- |
| `fn badge_offset(badge: ItemBadge, box_w: f32, box_h: f32, icon_size: f32, slack: (f32, f32)) -> (f32, f32)` | Corner-badge offset `(top, right)` from the icon box's top-right corner (negative = outside the box) for an icon box of `box_w × box_h`.
