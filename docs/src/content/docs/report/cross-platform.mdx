## macOS

How it was validated:

- Every phase was type-checked from Linux with
  `scripts/macos-check/check.sh` (`cargo check --target aarch64-apple-darwin`
  with stubbed system tools, plus a syntax check of the MSL shim).
- On the Mac itself, each phase was delivered, and the full suite and docs
  build passed there (latest, 2026-11-27: 175 tests, 116 docs pages).
- The gallery ran on Metal with no shader compile error or panic:
  material stories, `desktop-showcase`, `notification-center`, `select`.

Still to confirm on the Mac:

- The look of materials in both appearances, compared with the Linux
  screenshots.
- Frame rates: run `scripts/bench.sh`.
- Create and commit the macOS visual baselines
  (`scripts/visual-regression.sh --update`). The terminal needs the Screen
  Recording permission.
- Reduced motion (`ReducedMotion`) and reduced transparency.

## Linux

Every check runs here (the development box): X11 through Xvfb, Vulkan on
lavapipe (software). This covers:

- The full suite.
- All 180 screenshots.
- Visual regression against committed baselines.
- Benchmarks.

Not validated:

- Wayland sessions. They use the same Blade renderer; window decorations
  follow GPUI's Wayland client.
- Hardware GPUs (Mesa radv / anv, NVIDIA).

## Windows

Not run on a Windows machine. What is covered:

- Shared code builds on all targets.
- `WindowsAdapter` (caption buttons, labels, persistent scrollbars) is
  unit-tested and previewed in the gallery via the OS picker
  (`chrome_os`).
- DirectX returns `backdrop_blur_supported() == false`, so every material
  paints its opaque fallback (fill, grain, quad lighting, border). The
  `material` feature therefore works, without blur.

To validate on Windows:

```sh
cargo test --workspace --all-features
cargo run --release -p refineui-gallery
scripts/visual-regression.sh --update   # Git Bash; then compare on later runs
```
