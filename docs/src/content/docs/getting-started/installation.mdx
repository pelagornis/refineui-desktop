RefineUI GPUI targets GPUI `0.2.2`. macOS is the primary platform; Linux and Windows build and run the gallery. It needs Rust 1.98 or newer (required by the `refineui-system-icons` crate).

## Add the crate

```toml
# Cargo.toml
[dependencies]
gpui = "0.2.2"
refineui = { git = "https://github.com/pelagornis/refineui-desktop" }
```

Default features: `bundled-fonts` (embeds Inter) and `syntax-highlight`
(CodeBlock colours). Use `default-features = false` if your app ships its
own fonts or does not need highlighting. The other features (`material`,
`serde`, `web-extras`) are listed in the
[architecture overview](/architecture/overview/#cargo-features).

### Materials (real backdrop blur)

The `material` feature puts components on the Material Engine
(`refineui-material`). Blur needs a small renderer patch to gpui 0.2.2 that
ships in this repository (`vendor/gpui`), so patch gpui to it — the graph
still has exactly one gpui:

```toml
[dependencies]
gpui = "0.2.2"
refineui = { git = "https://github.com/pelagornis/refineui-desktop", features = ["material"] }

[patch.crates-io]
gpui = { git = "https://github.com/pelagornis/refineui-desktop" }
```

Without the feature everything works on stock gpui and frosted surfaces use
an opaque pre-composited fill. See [Material Components](/foundations/material-components/).

## Initialise

```rust
use gpui::{
    App, AppContext, Application, Context, IntoElement, ParentElement, Render, Styled, Window,
    WindowOptions, px,
};
use refineui::prelude::*;

struct Hello;

impl Render for Hello {
    fn render(&mut self, _: &mut Window, cx: &mut Context<Self>) -> impl IntoElement {
        refineui::root(cx)
            .p(px(24.))
            .child(Button::new("hello", "Hello RefineUI").on_click(|_, _, _| println!("hi")))
    }
}

fn main() {
    Application::new()
        .with_assets(refineui::Assets) // icons + spinner
        .run(|cx: &mut App| {
            refineui::init(cx); // fonts, theme, key bindings
            cx.open_window(WindowOptions::default(), |_, cx| cx.new(|_| Hello)).unwrap();
            cx.activate(true);
        });
}
```

`refineui::root(cx)` gives your window the theme background, text color, font and
Tab / Shift-Tab focus traversal.

## Run the gallery

```sh
git clone https://github.com/pelagornis/refineui-desktop
cd refineui-desktop
cargo run -p refineui-gallery
```
