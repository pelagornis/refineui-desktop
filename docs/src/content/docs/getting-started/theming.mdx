The theme is a GPUI global. Read it anywhere with `cx.theme()`:

```rust
let theme = cx.theme();
div()
    .bg(theme.colors.background_surface)
    .text_color(theme.colors.foreground_secondary)
    .shadow(theme.shadow(Elevation::FLOATING))
```

## Appearance

```rust
use refineui::{Appearance, Theme};

Theme::set_appearance(Appearance::Dark, cx);
Theme::toggle_appearance(cx);

// Follow the OS (call from a window observer):
Theme::sync_system_appearance(window, cx);
```

Every window re-renders when the appearance changes.

## Density

The default is **comfortable**, the web sizes (buttons 28 / 36 / 48 px).
Dense tools can switch to **compact** (22 / 28 / 32 px) or larger targets to
**spacious** (32 / 40 / 52 px) per app:

```rust
Theme::set_density(Density::Compact, cx);
```

See [Density](/architecture/density/) for every metric.

## Raw tokens

The `refineui-foundation` crate has no GPUI dependency and exposes the
RefineUI palette, semantic colors, spacing, radius, stroke, opacity,
typography, shadow, motion, blur and material values. It is re-exported as
`refineui::tokens` (`refineui-tokens` is a compatibility alias).
