## Usage

- Glyphs come from the `refineui-system-icons` crate (git dependency on pelagornis/refineui-system-icons, `default-features = false`) and are served by `refineui::Assets`; register it with `Application::new().with_assets(refineui::Assets)`.
- `Icon::new(IconName::…)` uses the curated set components rely on; `Icon::named(refineui::system_icons::icons::AIRPLANE)` reaches any of the 890 glyphs.
- The optical source size (16/20/24/28/32/48) is chosen from the rendered size, so a 24px icon uses the 24px drawing.
- Add a curated icon: append it to `CURATED` in `scripts/gen_icons.py`, then `python3 scripts/gen_icons.py`.

```rust
use refineui::prelude::*;

Icon::new(IconName::Settings).size(IconSize::Large).color(cx.theme().colors.foreground_secondary);
Icon::new(IconName::Star).style(IconStyle::Filled);
```

Open the live, interactive version in the gallery:

```sh
cargo run -p refineui-gallery -- --story icon
```

## API

Source: [`crates/refineui/src/icon.rs`](https://github.com/pelagornis/refineui-desktop/blob/main/crates/refineui/src/icon.rs)

### Icon

A monochrome SVG icon from the RefineUI System Icons set.

| Method | Description |
| --- | --- |
| `fn new(name: IconName) -> Self` | New icon (regular style, 16px, current text color). |
| `fn named(glyph: rsi::IconName) -> Self` | Any glyph of RefineUI System Icons (890 icons), e.g. `Icon::named(refineui::system_icons::icons::AIRPLANE)`. |
| `fn on_surface(mut self, kind: crate::SurfaceKind) -> Self` | Default color for a `crate::Surface` of `kind` (e.g. white on the HUD). An explicit `Self::color` still wins. |
| `fn style(mut self, style: IconStyle) -> Self` | Filled / regular. |
| `fn size(mut self, size: IconSize) -> Self` | Size. |
| `fn color(mut self, color: impl Into<Hsla>) -> Self` | Color (defaults to `foreground_primary`). |
| `fn transform(mut self, transformation: Transformation) -> Self` | Rotation / scale transform. |

### IconSize

Icon size steps — `iconSizes` (`global/sizes.ts`).

| Variant | Description |
| --- | --- |
| `XXSmall` | `xxsmall` — 12px |
| `XSmall` | `xsmall` — 16px (default) |
| `Small` | `small` — 20px |
| `Medium` | `medium` — 24px |
| `Large` | `large` — 28px |
| `XLarge` | `xlarge` — 32px |
| `XXLarge` | `xxlarge` — 48px |
| `Custom(Pixels)` | Explicit size. |

| Method | Description |
| --- | --- |
| `fn px(self) -> Pixels` | Size in pixels. |

### IconStyle

Icon outline style.

| Variant | Description |
| --- | --- |
| `Regular` | Outline (default). |
| `Filled` | Solid. |
