Stack, Grid, Box and Spacer presets (web `Layout`); gaps and paddings take the spacing tokens.

<Screenshot id="layout" alt="Layout variants and states" />

## Usage

- `h_stack(gap)` / `v_stack(gap)` — web `Stack` (the row centres its items); `spacer()` — web `Spacer`.
- `grid(columns, gap)` — web `Grid`; give children `.col_span(n)` for `GridItem span`.
- `token_box(padding, background, radius, border)` — web `Box`.
- `container()` / `container_with(padding_x)` — web `Container` (24px inline padding) — are behind the optional `web-extras` feature; desktop layouts use split views and panels instead.
- In a grid, avoid children that are `w_full()` flex rows (Taffy resolves their percentage width against the whole grid).

```rust
use refineui::prelude::*;

grid(3, 8.)
    .child(card_a)
    .child(card_b.col_span(2));

h_stack(8.)
    .child(title)
    .child(spacer())
    .child(actions);
```

Open the live, interactive version in the gallery:

```sh
cargo run -p refineui-gallery -- --story layout
```

## API

Source: [`crates/refineui/src/components/layout.rs`](https://github.com/pelagornis/refineui-desktop/blob/main/crates/refineui/src/components/layout.rs)

### Functions

| Function | Description |
| --- | --- |
| `fn h_stack(gap: f32) -> Div` | Horizontal flex row, items centred, `gap` px (web `Stack direction="row" align="center"`). |
| `fn v_stack(gap: f32) -> Div` | Vertical flex column, `gap` px (web `Stack`). |
| `fn spacer() -> Div` | Flexible spacer that pushes siblings apart (web `Spacer`). |
| `fn grid(columns: u16, gap: f32) -> Div` | Equal-column CSS grid (web `Grid columns gap`). Use `.col_span(n)` on children for web `GridItem span`. |
| `fn container() -> Div` | Full-width column with horizontal padding (web `Container`, default `sizeXXLarge` = 24px). *(feature `web-extras`)* |
| `fn container_with(padding_x: f32) -> Div` | `container` with a custom horizontal padding. *(feature `web-extras`)* |
| `fn token_box(padding: f32, background: Option<Hsla>, radius: f32, border: Option<(f32, Hsla)>) -> Div` | Token box (web `Box padding background radius border borderColor`). |
