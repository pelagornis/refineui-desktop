## Usage

- Read colors with `cx.theme().colors`. Never hard-code hex values in components.
- Regenerate from the web tokens with `python3 scripts/sync_tokens.py`.

```rust
use refineui::prelude::*;

let c = cx.theme().colors;
div().bg(c.background_surface).border_1().border_color(c.border_subtle).text_color(c.foreground_secondary)
```

Open the live, interactive version in the gallery:

```sh
cargo run -p refineui-gallery -- --story colors
```
