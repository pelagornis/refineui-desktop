The panels of one dock, as a compact tab strip or as stacked collapsible panels.

## Usage

- `Panel::new(id, title)` is a titled region: a `panel_header_height` header (Caption 2 semibold, `foregroundSecondary`, trailing `action`s) over its content. `.collapsible(true)` adds a chevron and makes the header one Tab stop (Enter / Space toggle, ← collapse, → expand).
- `PanelGroup::new(id)` holds `PanelEntry`s. `PanelGroupMode::Tabs` shows a tab strip (active tab `foregroundPrimary` with a 2px brand underline) and the active panel; `PanelGroupMode::Stack` stacks collapsible panels, Explorer style.
- Panel tabs and headers drag (`PanelDrag`, grab cursor, preview chip). Dropping on a strip shows a drop indicator and reports the insertion slot through `on_drop`. The strip is one Tab stop: ← / → activate the neighbour.
- Put a Panel Group in a `Dock` to place it on a window edge.

```rust
use refineui::prelude::*;

PanelGroup::new("left-panels")
    .mode(PanelGroupMode::Tabs)
    .side(DockSide::Left)
    .entry(PanelEntry::new("explorer", "Explorer").icon(IconName::Folder).child(files))
    .entry(PanelEntry::new("search", "Search").icon(IconName::Search).child(search))
    .active(Some(self.left_panel))
    .on_activate(cx.listener(|this, id: &str, _, cx| this.show_panel(id, cx)))
```

Open the live, interactive version in the gallery:

```sh
cargo run -p refineui-gallery -- --story panel-group
```

## API

Source: [`crates/refineui/src/workspace/panel.rs`](https://github.com/pelagornis/refineui-desktop/blob/main/crates/refineui/src/workspace/panel.rs)

### PanelGroup

A dock's panels.

| Method | Description |
| --- | --- |
| `fn new(id: impl Into<ElementId>) -> Self` | Empty group. |
| `fn mode(mut self, mode: PanelGroupMode) -> Self` | Tabs or Stack. |
| `fn side(mut self, side: DockSide) -> Self` | The dock it sits in (recorded in drags). |
| `fn entry(mut self, e: PanelEntry) -> Self` | Add a panel. |
| `fn active(mut self, ix: Option<usize>) -> Self` | Active panel index (Tabs mode). |
| `fn action(mut self, e: impl IntoElement) -> Self` | Group-level trailing action (zoom, hide — added by `super::Dock`). |
| `fn on_activate(mut self, f: impl Fn(&str, &mut Window, &mut App) + 'static) -> Self` | A panel tab was activated. |
| `fn on_drop(mut self, f: impl Fn(&PanelDrag, usize, &mut Window, &mut App) + 'static) -> Self` | A panel was dropped at insertion slot `usize` (as shown). |
| `fn len(&self) -> usize` | Panel count. |
| `fn is_empty(&self) -> bool` | No panels. |

### PanelEntry

One panel of a `PanelGroup`.

| Method | Description |
| --- | --- |
| `fn new(id: impl Into<String>, title: impl Into<SharedString>) -> Self` | Panel `id` titled `title`. |
| `fn icon(mut self, icon: IconName) -> Self` | Tab / header icon. |
| `fn action(mut self, e: impl IntoElement) -> Self` | Header action (shown while the panel is active / expanded). |
| `fn child(mut self, e: impl IntoElement) -> Self` | Content. |

### PanelGroupMode

How a `PanelGroup` shows its panels.

| Variant | Description |
| --- | --- |
| `Tabs` | Tab strip + active panel (bottom dock, inspector). |
| `Stack` | Collapsible panels stacked vertically (Explorer). |
