## Usage

- `open_floating_panel(options, cx, content, on_event)` opens a `WindowKind::Floating` window at `FloatingPanelOptions::bounds` (screen px) with a compact 32px titlebar: the title, a Dock button and close.
- On macOS the window background is blurred and the panel fill is the translucent `surfaceFrosted`, so the desktop shows through; elsewhere the fill is opaque `backgroundPrimary` (`FloatingPanelOptions::blurred` tells which).
- Moves and resizes arrive as `FloatingPanelEvent::Bounds` for `WorkspaceLayout::set_floating_bounds`; the Dock button sends `FloatingPanelEvent::Dock` and closing the window `FloatingPanelEvent::Closed`.
- `FloatingPanelFrame` is the window content as a plain element, for previews like the one above; it is a preview (border and shadow, no window drag) until `.interactive(true)`.

```rust
use refineui::prelude::*;

open_floating_panel(
    FloatingPanelOptions::new("outline", "Outline", [120., 120., 320., 480.]),
    cx,
    |_, _| outline_view().into_any_element(),
    |panel, event, cx| match event {
        FloatingPanelEvent::Dock => dock_panel(panel, cx),
        FloatingPanelEvent::Bounds(b) => save_bounds(panel, b, cx),
        FloatingPanelEvent::Closed => {}
    },
);
```

Open the live, interactive version in the gallery:

```sh
cargo run -p refineui-gallery -- --story floating-panel
```

## API

Source: [`crates/refineui/src/shell/floating_panel.rs`](https://github.com/pelagornis/refineui-desktop/blob/main/crates/refineui/src/shell/floating_panel.rs)

### FloatingPanelFrame

The floating panel's content as an element.

| Method | Description |
| --- | --- |
| `fn new(id: impl Into<ElementId>, title: impl Into<SharedString>) -> Self` | Frame titled `title`. |
| `fn blurred(mut self, blurred: bool) -> Self` | Translucent fill (the window background is blurred). |
| `fn interactive(mut self, interactive: bool) -> Self` | A live window (titlebar drags / closes it); `false` for previews, which also get a border and shadow. |
| `fn on_dock(mut self, f: impl Fn(&mut Window, &mut App) + 'static) -> Self` | The Dock button. |
| `fn child(mut self, e: impl IntoElement) -> Self` | Content. |

### FloatingPanelOptions

How to open a floating panel.

| Method | Description |
| --- | --- |
| `fn new(panel: impl Into<String>, title: impl Into<SharedString>, bounds: [f32; 4]) -> Self` | Panel `panel` titled `title` at `bounds`, blurred where supported. |
| `fn blurred(&self) -> bool` | Whether this platform will blur (macOS with `blur`). |
| `fn window_options(&self) -> WindowOptions` | GPUI window options. |

### FloatingPanelEvent

What happened to a floating panel window.

| Variant | Description |
| --- | --- |
| `Bounds([f32; 4])` | Moved or resized: `[x, y, width, height]`, screen px. |
| `Dock` | The Dock button: put the panel back (the window closes itself). |
| `Closed` | The window was closed by the user. |
