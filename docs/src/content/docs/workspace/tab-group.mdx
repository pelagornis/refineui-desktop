## Usage

- `DocumentTab::new(id, title)` describes one open document. `.dirty(true)` shows a dot in the close slot that turns into × on hover; `.pinned(true)` makes a compact icon-only tab in the leading run with no close button; `.preview(true)` sets the title in italics (the next preview replaces it; double-click or `on_promote` keeps it).
- `TabBar::new(id, group)` is the strip: `surfaceSunken` bar, the active tab in `backgroundPrimary` with a 2px brand line on top while `.focused(true)` (`borderStrong` otherwise). Tabs activate on mouse-down, middle-click closes, and the close button shows on the active and hovered tab.
- Right-click opens the tab menu; its choices come back as `TabCommand`s through `on_command`. Tabs drag (`TabDrag`, with a preview chip) to reorder within the bar (`on_drop` gets the slot) or onto another group.
- When the tabs overflow, the strip scrolls (keeping the active tab in view) and a chevron lists every tab. The strip is one Tab stop: ← / → activate the neighbour, Home / End the ends.
- `TabGroup::new(id).bar(bar).child(editor)` adds the content. While a tab is dragged over it a drop zone shows where it lands: the middle joins the group, an edge splits it (`on_zone_drop` gets the `DockZone`).

```rust
use refineui::prelude::*;

TabGroup::new("editor-group")
    .bar(
        TabBar::new("editor-tabs", "main")
            .tab(DocumentTab::new("lib", "lib.rs").pinned(true))
            .tab(DocumentTab::new("main", "main.rs").dirty(true))
            .active(Some(1))
            .focused(true)
            .on_select(cx.listener(|this, id: &str, _, cx| this.activate(id, cx)))
            .on_close(cx.listener(|this, id: &str, _, cx| this.close(id, cx))),
    )
    .child(editor)
```

### TabCommand

A tab context-menu command.

| Variant | Description |
| --- | --- |
| `Close` | Close this tab. |
| `CloseOthers` | Close every other unpinned tab. |
| `CloseToRight` | Close unpinned tabs to the right. |
| `CloseAll` | Close every unpinned tab. |
| `Pin` | Pin. |
| `Unpin` | Unpin. |
| `KeepOpen` | Promote a preview tab. |
| `SplitRight` | Move into a new group on the right. |
| `SplitDown` | Move into a new group below. |
| `CopyPath` | Copy the document path (`tooltip`). |
