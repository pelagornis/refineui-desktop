## Usage

- `Dock::new(id, side)` is one window edge holding a `PanelGroup` (`.group(..)`) or any element (`.child(..)`). Its inner edge is a quiet resize handle; sizes are clamped to `.limits(min, max)` and reported through `on_resize`.
- The group header gets Maximize / Restore and Hide buttons (`on_zoom`, `on_hide`). Dropping a `PanelDrag` on the dock appends it (`on_drop`); while a panel drag hovers, the dock tints `backgroundBrandSubtle`.
- `DockArea::new(id).center(..).dock(..)` lays out the center and its docks. While a panel is dragged, drop zones appear along the center's left, right and bottom edges so a panel can move to a hidden dock (`on_edge_drop`). `.zoomed(Some(side))` fills the area with that dock.
- Inside an `ApplicationShell`, pass the area to `.workspace(area)` so the docks become F6 focus regions. Keep the sizes in your `WorkspaceLayout` (`Docks`) to persist them.

```rust
use refineui::prelude::*;

DockArea::new("workspace")
    .center(editor)
    .dock(
        Dock::new("left", DockSide::Left)
            .size(self.left_width)
            .limits(160., 480.)
            .group(panels)
            .on_resize({
                let this = cx.entity();
                move |width, _, cx| {
                    this.update(cx, |this, cx| {
                        this.left_width = width;
                        cx.notify();
                    })
                }
            }),
    )
```

## API

Source: [`crates/refineui/src/workspace/dock.rs`](https://github.com/pelagornis/refineui-desktop/blob/main/crates/refineui/src/workspace/dock.rs)

### DockArea

Center + docks.

| Method | Description |
| --- | --- |
| `fn new(id: impl Into<ElementId>) -> Self` | Empty area. |
| `fn center(mut self, e: impl IntoElement) -> Self` | The editor area. |
| `fn dock(mut self, dock: Dock) -> Self` | A visible dock (its side decides where it goes). |
| `fn zoomed(mut self, side: Option<DockSide>) -> Self` | Fill the area with the dock on this side. |
| `fn on_edge_drop(mut self, f: impl Fn(&PanelDrag, DockSide, &mut Window, &mut App) + 'static) -> Self` | A panel was dropped on an edge zone. |

### Dock

One dock.

| Method | Description |
| --- | --- |
| `fn new(id: impl Into<ElementId>, side: DockSide) -> Self` | Dock on `side`. |
| `fn size(mut self, size: f32) -> Self` | Width (side docks) or height (bottom), px. |
| `fn limits(mut self, min: f32, max: f32) -> Self` | Size limits, px (default 120…640). |
| `fn default_size(mut self, size: f32) -> Self` | Size restored by double-clicking the edge. |
| `fn group(mut self, group: PanelGroup) -> Self` | The dock's panels (gets the zoom / hide buttons). |
| `fn child(mut self, e: impl IntoElement) -> Self` | Custom content instead of a `PanelGroup`. |
| `fn zoomed(mut self, zoomed: bool) -> Self` | Filling the workspace (shows Restore instead of Maximize). |
| `fn on_resize(mut self, f: impl Fn(f32, &mut Window, &mut App) + 'static) -> Self` | New size from the edge handle. |
| `fn on_zoom(mut self, f: impl Fn(&mut Window, &mut App) + 'static) -> Self` | Maximize / Restore pressed. |
| `fn on_hide(mut self, f: impl Fn(&mut Window, &mut App) + 'static) -> Self` | Hide pressed. |
| `fn on_drop(mut self, f: impl Fn(&PanelDrag, &mut Window, &mut App) + 'static) -> Self` | A panel dropped on the dock outside its strip (append). |
| `fn side(&self) -> DockSide` | The side. |
| `fn current_size(&self) -> f32` | Current size. |

### DockSide

One of the three dock areas.

| Variant | Description |
| --- | --- |
| `Left` | Leading (primary sidebar). |
| `Right` | Trailing (secondary sidebar, inspector). |
| `Bottom` | Bottom (terminal, output). |

### Functions

| Function | Description |
| --- | --- |
| `fn clamp_dock_size(size: f32, min: f32, max: f32) -> f32` | Clamp a dock size (`min` wins when the limits cross). |
