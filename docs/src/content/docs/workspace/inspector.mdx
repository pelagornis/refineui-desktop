The property sheet of the current selection, in collapsible sections.

<Screenshot id="inspector" alt="Inspector variants and states" />

## Usage

- `InspectorSection::new(title)` is a collapsible group (a Panel header) of `.row(label, value)` rows: labels in Body 3 `foregroundSecondary` in a fixed 96px column, values in the rest; rows are at least `row_height` tall.
- With no sections the inspector shows an empty state ("No selection" by default, `.empty_text(..)` to change it). Long sheets scroll.
- It usually lives in the right dock.

```rust
use refineui::prelude::*;

Inspector::new("inspector")
    .section(
        InspectorSection::new("Layout")
            .row("Width", Text::new("320 px"))
            .row("Height", Text::new("Auto")),
    )
    .section(InspectorSection::new("Advanced").collapsed(true))
```

Open the live, interactive version in the gallery:

```sh
cargo run -p refineui-gallery -- --story inspector
```

### Inspector

The property sheet.

| Method | Description |
| --- | --- |
| `fn new(id: impl Into<ElementId>) -> Self` | Empty inspector. |
| `fn header(mut self, e: impl IntoElement) -> Self` | Element above the sections (selection name, kind badge). |
| `fn section(mut self, s: InspectorSection) -> Self` | Add a section. |
| `fn empty_text(mut self, t: impl Into<SharedString>) -> Self` | Empty-state text. |

### InspectorSection

A titled group of property rows.

| Method | Description |
| --- | --- |
| `fn new(title: impl Into<SharedString>) -> Self` | Section titled `title`. |
| `fn row(mut self, label: impl Into<SharedString>, value: impl IntoElement) -> Self` | A `label` / value row. |
| `fn child(mut self, e: impl IntoElement) -> Self` | A full-width row (no label). |
| `fn collapsed(mut self, collapsed: bool) -> Self` | Start collapsed. |
