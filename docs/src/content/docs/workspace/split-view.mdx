Panes along an axis, sized by ratios, with a resize handle on every inner boundary.

<Screenshot id="split-view" alt="Split View variants and states" />

## Usage

- `SplitView::horizontal(id)` / `SplitView::vertical(id)` lay the children side by side or stacked. Controlled: pass `.ratios(..)` and store what `.on_resize(..)` reports (usually in a `PaneNode::Split`). Without `.ratios` the view keeps its own ratios in keyed state.
- `min_size` is a per-child minimum in px (one value applies to every child; default 120). Dragging a handle only moves the two panes next to it (`resize_at`).
- The handle is a `borderSubtle` hairline with a density-sized hit area (`splitter_hit`, 4–8px) and a column / row resize cursor that stays for the whole drag. Hover, drag and keyboard focus thicken it to a 2px `borderFocus` line.
- Each handle is one Tab stop: ← / → (↑ / ↓ when stacked) move it 8px, ⇧ 40px, Home / End collapse to the minimum / maximum; double-click resets to equal sizes.
- `PaneTree::new(id, &node, render_group)` renders a whole `PaneNode` tree: splits become Split Views and each leaf (`TabGroupState`) is drawn by your closure, usually as a Tab Group. Resizes come back as `(path, ratios)` for `WorkspaceLayout::set_ratios`; `.zoomed(Some(group))` renders only that group.

```rust
use refineui::prelude::*;

SplitView::horizontal("main")
    .ratios(self.ratios.clone())
    .min_size(vec![160., 320.])
    .on_resize(cx.listener(|this, ratios: &[f32], _, cx| {
        this.ratios = ratios.to_vec();
        cx.notify();
    }))
    .child(sidebar)
    .child(editor)
```

## API

Source: [`crates/refineui/src/workspace/split_view.rs`](https://github.com/pelagornis/refineui-desktop/blob/main/crates/refineui/src/workspace/split_view.rs)

### SplitView

Children along an axis with handles between them.

| Method | Description |
| --- | --- |
| `fn new(id: impl Into<ElementId>, axis: SplitAxis) -> Self` | An empty split. |
| `fn horizontal(id: impl Into<ElementId>) -> Self` | Side-by-side split. |
| `fn vertical(id: impl Into<ElementId>) -> Self` | Stacked split. |
| `fn child(mut self, child: impl IntoElement) -> Self` | Add a pane. |
| `fn children(mut self, children: impl IntoIterator<Item = impl IntoElement>) -> Self` | Add panes. |
| `fn ratios(mut self, ratios: Vec<f32>) -> Self` | Controlled sizes (fractions; normalized if they don't fit). |
| `fn min_size(mut self, min: impl Into<Vec<f32>>) -> Self` | Minimum px per pane (one value for all, or one per pane). |
| `fn on_resize(mut self, f: impl Fn(&[f32], &mut Window, &mut App) + 'static) -> Self` | New ratios after a drag, keyboard step or reset. |

### ResizeHandle

A splitter.

| Method | Description |
| --- | --- |
| `fn new(id: impl Into<ElementId>, axis: SplitAxis) -> Self` | A handle between panes laid out along `axis` (`Horizontal` = side by side → a vertical line with a column-resize cursor). |
| `fn drag(mut self, drag: ResizeDrag) -> Self` | Start a drag with this payload (the owner listens with `on_drag_move::<ResizeDrag>`). |
| `fn on_step(mut self, f: impl Fn(f32, &mut Window, &mut App) + 'static) -> Self` | Keyboard nudge, px (negative = toward the start; `±INFINITY` for Home / End). |
| `fn on_reset(mut self, f: impl Fn(&mut Window, &mut App) + 'static) -> Self` | Double-click. |
| `fn align(mut self, align: HandleAlign) -> Self` | Hit area placement (default centered). |
| `fn quiet(mut self, quiet: bool) -> Self` | No hairline at rest (the container already draws a border); the 2px focus line still shows on hover / drag / focus. |
| `fn focusable(mut self, focusable: bool) -> Self` | Not a tab stop (default: one tab stop). |

### HandleAlign

Where a `ResizeHandle`'s hit area sits relative to its boundary.

| Variant | Description |
| --- | --- |
| `Center` | Centered on the boundary (between two panes). |
| `Start` | After the boundary (line at the start) — e.g. a right dock's edge. |
| `End` | Before the boundary (line at the end) — e.g. a left dock's edge. |

### PaneTree

Renders a `PaneNode` tree.

| Method | Description |
| --- | --- |
| `fn new(id: impl Into<ElementId>, node: &PaneNode, render_group: impl Fn(&TabGroupState, &mut Window, &mut App) -> AnyElement + 'static) -> Self` | Render `node`, drawing each tab group with `render_group`. |
| `fn on_resize(mut self, f: impl Fn(&[usize], &[f32], &mut Window, &mut App) + 'static) -> Self` | A split's ratios changed: `(path to the split, ratios)`. |
| `fn zoomed(mut self, group: Option<String>) -> Self` | Show only this group (zoom). |
| `fn min_size(mut self, px: f32) -> Self` | Minimum pane size, px (default 160). |

### SplitAxis

Split direction.

| Variant | Description |
| --- | --- |
| `Horizontal` | Children side by side. |
| `Vertical` | Children stacked. |

### PaneNode

A node of the center area.

| Variant | Description |
| --- | --- |
| `Split { .. }` | Children along `axis`, sized by `ratios` (same length, sum 1). |
| `Tabs(TabGroupState)` | A tab group (leaf). |

| Method | Description |
| --- | --- |
| `fn at(&self, path: &[usize]) -> Option<&PaneNode>` | The node at `path` (child indices from this node). |
| `fn at_mut(&mut self, path: &[usize]) -> Option<&mut PaneNode>` | Mutable `Self::at`. |

### Functions

| Function | Description |
| --- | --- |
| `fn hold_resize_cursor(axis: SplitAxis, window: &mut Window, cx: &mut App)` | Keep the resize cursor for the whole drag (call from `on_drag_move`). |
| `fn fit_ratios(ratios: Option<&[f32]>, n: usize) -> Vec<f32>` | Make `ratios` fit `n` panes (equal when they don't). |
| `fn nudge_ratios(ratios: &[f32], ix: usize, delta_px: f32, extent_px: f32, mins: &[f32]) -> Vec<f32>` | Move boundary `ix` by `delta_px` of `extent_px` (keyboard nudges; `±INFINITY` clamps to the minimum / maximum). |
